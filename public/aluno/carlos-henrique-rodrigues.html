Etapa 1.4: Grammar Tip -- Verbo to be (ser / estar)

GRAMMAR

Em português são dois verbos, ser e estar. Em inglês é um só: to be. / In Portuguese there are two verbs. In English there is one: to be.

Uso / UseEstrutura / PatternExemplo / Example
Eu / II am = I’mI am Carlos. (Eu sou o Carlos.)
Você / Youyou are = you’reYou are very kind. (Você é muito gentil.)
Ele, ela, isso / He, she, itit is = it’sThe car is in the parking lot. (O carro está no estacionamento.)
Negativa / Negativeam not / is not / are notInsurance is not included. (O seguro não está incluído.)
Pergunta / Questiono verbo vem primeiro: Is...? Are...?Are you from Brazil? (Você é do Brasil?)
Ideia-chave / Key ideaIdade em inglês usa am, nunca "have": I am 65 years old (e não "I have 65 years"). E o verbo nunca some: "I Carlos" não existe, o certo é "I am Carlos". / Age uses "am", never "have". And the verb never disappears.

Etapa 1.4: Grammar Tip -- There is / There are (tem, há)

GRAMMAR

Em português dizemos "tem um lago". Em inglês, para lugar, nunca usamos "have": usamos there is / there are. / To describe a place, use there is / there are, never "have".

Uso / UseEstrutura / PatternExemplo / Example
Uma coisa / One thingthere is + a / anThere is a lake. (Tem um lago.)
Várias coisas / Many thingsthere are + pluralThere are mountains. (Tem montanhas.)
Negativa / Negativethere is not / there are noThere are no Brazilian restaurants. (Não tem restaurante brasileiro.)
Pergunta / QuestionIs there...? / Are there...?Is there a station? (Tem estação?)
Resposta curta / Short answerYes, there is. / No, there is not.Is there a lake? Yes, there is. (Tem, sim.)
Ideia-chave / Key idea"Tem" em português vira there is / there are quando falamos de um lugar. "Have a lake" não existe em inglês. / "Tem" becomes there is / there are for places. "Have a lake" does not exist in English.

Etapa 1.4: Grammar Tip -- Present simple com he e she

GRAMMAR

Com he, she e it, o verbo ganha um -s. Na pergunta e na negativa, o -s vai para o does. / With he, she and it, the verb takes -s. In questions and negatives, the -s goes to does.

Uso / UseEstrutura / PatternExemplo / Example
Afirmativa / Affirmativehe / she + verbo + sHe works with me. (Ele trabalha comigo.)
Verbos especiais / Special verbsgo → goes · have → hasHe has a meeting. (Ele tem uma reunião.)
Negativa / Negativehe / she + doesn’t + verboHe doesn’t work late. (Ele não trabalha até tarde.)
Pergunta / QuestionDoes + he / she + verbo?Does he work with you? (Ele trabalha com você?)
Resposta curta / Short answerYes, he does. / No, he doesn’t.Does your son work? Yes, he does. (Trabalha, sim.)
Ideia-chave / Key ideaSó existe UM -s na frase: ou no verbo (he works) ou no does (does he work?). "Does he works" está errado. / Only ONE -s per sentence: on the verb or on does.

Etapa 1.3: Grammar in Context

GRAMMAR

Leia o texto em voz alta, devagar, e depois responda as perguntas.

Carlos and his wife are at a restaurant in Miami. The waiter asks: "Would you like a table for two?" "Yes, please."

They read the menu. Carlos says: "I would like the fish, and my wife would like the salad." They order a glass of wine too.

At the end, Carlos says: "The check, please." The tip is not included, so he writes twenty percent.

1. O que a esposa do Carlos pede? (What does his wife order?)
A O peixe. (The fish.)
B A salada. (The salad.)
C A sobremesa. (Dessert.)
2. Por que "my wife WOULD LIKE", sem -s? (Why no -s?)
A Porque would like nunca leva -s. (Because would like never takes -s.)
B Porque é passado. (Because it is past.)
C Porque é uma pergunta. (Because it is a question.)
3. Como o garçom oferece uma mesa? (How does the waiter offer a table?)
A "You want a table?"
B "Would you like a table for two?"
C "Do you would like a table?"

Etapa 1.4: Grammar Tip -- I would like (eu gostaria)

GRAMMAR

I want (eu quero) soa forte num restaurante. I would like (eu gostaria) é o jeito educado. / "I want" sounds strong. "I would like" is the polite way.

Uso / UseEstrutura / PatternExemplo / Example
Pedido educado / Polite requestI would like + coisaI would like the fish. (Eu gostaria do peixe.)
Forma curta / Short formI would = I’dI’d like water. (Eu gostaria de água.)
Outra pessoa / Another personshe / he + would like (sem -s)My wife would like the salad. (Minha esposa gostaria da salada.)
Oferta / OfferWould you like...?Would you like dessert? (Você gostaria de sobremesa?)
Com verbo / With a verbwould like + to + verboWe would like to order. (Gostaríamos de pedir.)
Ideia-chave / Key ideaWould like nunca muda: I, you, he, she, we. Nada de -s (aula 4) aqui. E quando o garçom oferece algo, responda Yes, please ou No, thank you. / Would like never changes. Answer an offer with "Yes, please" or "No, thank you".

Etapa 1.4: Grammar Tip -- Can / can't (pode, consegue)

GRAMMAR

Can serve para permissão (pode) e capacidade (consegue, sabe). É igual para todas as pessoas. / Can is for permission and ability. Same form for everyone.

Uso / UseEstrutura / PatternExemplo / Example
Permissão / Permissioncan + verboYou can ask questions. (Você pode fazer perguntas.)
Proibição / No permissioncan’t (cannot) + verboYou can’t take photos. (Você não pode tirar fotos.)
Capacidade / Abilitycan + verboMy son can speak English. (Meu filho sabe falar inglês.)
Pergunta / QuestionCan + I / we + verbo?Can I take a photo? (Posso tirar uma foto?)
Resposta curta / Short answerYes, you can. / No, you can’t.Can I touch it? No, you can’t. (Não pode.)
Ideia-chave / Key ideaCan é simples: nunca leva -s (he can), nunca usa do (Can I...?, e não "Do I can...?") e nunca vem com to (can drive, e não "can to drive"). / Can never takes -s, do or to.
