Etapa 1.4: Grammar Tip -- Verbo to be (ser / estar)

GRAMMAR

Em português são dois verbos, ser e estar. Em inglês é um só: to be. / In Portuguese there are two verbs. In English there is one: to be.

Uso / UseEstrutura / PatternExemplo / Example

Etapa 1.4: Grammar Tip -- There is / There are (tem, há)

Em português dizemos "tem um escritório". Em inglês, para dizer o que existe num lugar, nunca usamos "have": usamos there is / there are. / To say what exists in a place, use there is / there are, never "have".

Para o que você gosta (ou não gosta) de fazer: like / love / don't like + verbo com -ing. Para o que você quer: want to + verbo. / like + -ing; want + to + verb.

Uso / UseEstrutura / PatternExemplo / Example
Gostar / Likelike / love + -ingI like going to the gym. (Gosto de ir à academia.)
Não gostar / Not likedon’t like + -ingI don’t like watching TV. (Não gosto de ver TV.)
Querer / Wantwant to + verboI want to see live music. (Quero ver música ao vivo.)
Pergunta / QuestionDo you like...-ing? / Do you want to...?Do you want to come? (Você quer vir?)
Ele, ela / He, shelikes / wantsShe likes dancing. (Ela gosta de dançar.)
Ideia-chave / Key ideaEm português é "gosto DE ir" e "quero ir". Em inglês: "I like going" e "I want to go". Nunca "I want go" nem "I like go". / Never "I want go" or "I like go".

Etapa 1.4: Grammar Tip -- How much / How many (quanto, quantos)

GRAMMAR

Em português é tudo "quanto / quantos". Em inglês a pergunta muda: se dá para contar (clientes, cartões), how many; se não dá (dinheiro, tempo), how much. / Countable: how many. Uncountable: how much.

Uso / UseEstrutura / PatternExemplo / Example
Contável / CountableHow many + pluralHow many clients? (Quantos clientes?)
Incontável / UncountableHow much + singularHow much money? (Quanto dinheiro?)
Preço / PriceHow much is it?How much is the fee? (Quanto é a taxa?)
Respostas / Answersa lot / not many / not muchNot many problems. (Poucos problemas.)
Números grandes / Big numbersthousand, million (sem s)two million (dois milhões)
Ideia-chave / Key ideaPergunte: dá para contar? Um cliente, dois clientes: many. Um dinheiro, dois dinheiros? Não: much. E número não leva s: "two million", nunca "two millions". / Can you count it? Then many. Numbers have no s.
