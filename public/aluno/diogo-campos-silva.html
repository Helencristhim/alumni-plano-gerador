Etapa 1.4: Grammar Tip -- Verbo to be (ser / estar)

GRAMMAR

Em português são dois verbos, ser e estar. Em inglês é um só: to be. / In Portuguese there are two verbs. In English there is one: to be.

Uso / UseEstrutura / PatternExemplo / Example
Eu / II am = I’mI am Diogo. (Eu sou o Diogo.)
Você / Youyou are = you’reYou are the support analyst. (Você é a analista de suporte.)
Ele, ela, isso / He, she, itis = ’sThe ticket is open. (O chamado está aberto.)
Nós, eles / We, theyare = ’reWe are the IT team. (Nós somos a equipe de TI.)
Negativa / Negativeam not / is not / are notThe account is not working. (A conta não está funcionando.)
Pergunta / Questiono verbo vem primeiro: Is...? Are...?Is the ticket open? (O chamado está aberto?)
Ideia-chave / Key ideaO verbo nunca some: "I Diogo" ou "I analyst" não existe, o certo é "I am Diogo" e "I am an analyst". Na pergunta, o verbo vai para o começo: "Is it...?" / The verb never disappears. In a question, it goes first.

Etapa 1.4: Grammar Tip -- Presente simples: negativa e pergunta

GRAMMAR

Em português basta "não": "o site não abre". Em inglês precisa de um ajudante: don’t ou doesn’t. / In Portuguese you only need "não". In English you need a helper: don’t or doesn’t.

Uso / UseEstrutura / PatternExemplo / Example
Negativa: I, you, we, theydon’t + verboI don’t receive messages. (Eu não recebo mensagens.)
Negativa: he, she, itdoesn’t + verboThe website doesn’t open. (O site não abre.)
Pergunta: I, you, we, theyDo + sujeito + verbo?Do you see the error? (Você vê o erro?)
Pergunta: he, she, itDoes + sujeito + verbo?Does the email work? (O e-mail funciona?)
Resposta curta / Short answerYes, it does. / No, it doesn’t.Does it work? No, it doesn’t. (Não, não funciona.)
Ideia-chave / Key ideaNunca "the email no work": o certo é "the email doesn’t work". E depois de doesn’t / does o verbo fica sem -s: "doesn’t open", nunca "doesn’t opens". / Never "no work". After doesn’t and does, the verb has no -s.

Etapa 1.4: Grammar Tip -- Can / can’t (poder, conseguir)

GRAMMAR

"Can" serve para o que alguém consegue fazer e para pedir ajuda. É igual para todas as pessoas. / "Can" is for ability and for requests. It is the same for everybody.

Uso / UseEstrutura / PatternExemplo / Example
Afirmativa / Affirmativecan + verboLinda can reset the VPN. (A Linda pode reiniciar a VPN.)
Negativa / Negativecan’t + verboThe users can’t log in. (Os usuários não conseguem entrar.)
Pedido / RequestCan you + verbo?Can you help me? (Você pode me ajudar?)
Resposta curta / Short answerYes, they can. / No, I can’t.Can they access the internet? Yes, they can.
Ideia-chave / Key ideaSem "to" e sem -s: "she can reset", nunca "she cans" ou "can to reset". E nunca "no can": o certo é "can’t". / No "to", no -s, and never "no can".

A instrução começa direto com o verbo, sem "you". / An instruction starts with the verb, with no "you".

Faça / Do itverbo + ...Restart the computer. (Reinicie o computador.)
Não faça / Don’t do itdon’t + verboDon’t close the window. (Não feche a janela.)
Educado / Politeplease + verboPlease send me a screenshot. (Por favor, me mande um print.)
Ordem / Orderfirst, then, after thatFirst, check the cable. Then open the app. (Primeiro... depois...)
Ideia-chave / Key ideaNunca "no close": o certo é "don’t close". E sem "to" e sem -s: "click", nunca "to click" ou "clicks". / Never "no close". No "to", no -s.

Karen is installing an update on the server. The user is not waiting anymore: she is reading her emails. The problem is fixed.

1. O que o Diogo está fazendo? (What is Diogo doing?)
A Ele está instalando o servidor novo sozinho. (He is installing a new server.)
B Ele está lendo os e-mails. (He is reading emails.)
C Ele está compartilhando a tela. (He is sharing his screen.)
2. Como se diz "Está carregando" em inglês?
A "It loading now on the screen."
B "It is loading."
C "It is load."
3. Por que o texto usa "is installing" e não "installs"? (Why "is installing"?)
A Porque a ação está acontecendo agora. (The action is happening now.)
B Porque a ação acontece todo dia, é rotina. (It is a routine.)
C Porque é uma instrução para o usuário. (It is an instruction.)

Etapa 1.4: Grammar Tip -- Presente contínuo (o que acontece agora)

GRAMMAR

É o nosso "estou fazendo": verbo to be (am / is / are) + verbo com -ing. / It is like "estou fazendo": am / is / are + verb-ing.

Uso / UseEstrutura / PatternExemplo / Example
Eu / II am + verbo-ingI am sharing my screen. (Estou compartilhando a minha tela.)
Ele, ela, isso / He, she, itis + verbo-ingThe page is loading. (A página está carregando.)
Nós, eles / We, theyare + verbo-ingThey are fixing the server. (Eles estão consertando o servidor.)
Negativa / Negativeis not / are not + verbo-ingThe VPN is not working. (A VPN não está funcionando.)
Pergunta / QuestionWhat are you + verbo-ing?What are you doing? (O que você está fazendo?)
Ideia-chave / Key ideaO "estou" não pode sumir: "I sharing" está errado, o certo é "I am sharing". / Never forget am, is or are before the -ing.
