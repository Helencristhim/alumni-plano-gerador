Lesson 03 -- Pre-class

The Hospital Project -- Telling a Project Story

A partner asks for an example of a project. Key words: a site survey, to upgrade, downtime, a deadline, on schedule, a setback, to run into, a workaround, to go live, a handover. Structure: past simple with first, then, after that, in the end.

Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example. Tap Listen to hear it.

A site survey -- a visit to a building to study it before you plan a project
"We did a site survey before we wrote the proposal."
To upgrade -- to make a system better or more modern
"The hospital upgraded its network last year."
Downtime -- a period when a system is not working
"In a hospital, one hour of downtime is a big problem."
A deadline -- the date or time when a job must be finished
"The deadline was the end of June."
On schedule -- at the time that was planned, not late
"We finished the installation on schedule."
A setback -- a problem that makes a project slower or more difficult
"We had a setback in the second week: the cables arrived late."
To run into -- to find a problem that you did not expect
"We ran into a problem with the old walls."
A workaround -- a way to solve a problem when the normal way is not possible
"We found a workaround: we worked at night."
To go live -- to start working for real, for the users
"The new system went live on a Sunday morning."
A handover -- the moment when you give a finished project to the client
"At the handover, we trained the hospital team."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text, then answer the questions.

Last year a hospital in São Paulo needed a new network. First, the partner’s engineers visited the building and did a site survey. Then they planned the work floor by floor, because the hospital could not have any downtime.

In the third week, the team ran into a setback: some cables arrived late. After that, they found a workaround and worked on other floors while they waited.

In the end, the new network went live on schedule. The hospital didn’t have a single hour of downtime.

1. What did the engineers do first?
A They installed the new network.
B They visited the building and did a site survey.
C They trained the hospital team.
2. Which verbs in the text are irregular?
A visited, planned, worked
B did, ran, found, went
C arrived, needed, planned
3. Which sentence is correct?
A “The hospital didn’t had any downtime.”
B “The hospital didn’t have any downtime.”
C “The hospital not have any downtime.”

Stage 1.4: Grammar Tip -- Past Simple for a Project Story

GRAMMAR

Regular verbs take -ed; irregular verbs change. After did, the verb goes back to its simple form. First, then, after that and in the end give the order.

JobFormExample
Regular verbsverb + -edWe installed the cameras.
Irregular verbsa new form: go → went, find → found, run → ranThe system went live.
Negativedidn’t + verb (no -ed)We didn’t have any downtime.
QuestionDid + subject + verb?Did you finish on schedule?
The orderfirst, then, after that, in the endFirst we visited; in the end it went live.
The trapafter did, the simple verbNot did you finished. Say did you finish?

Never: Last year we install · We runned into a problem · Did you finished? · We didn’t had any downtime
