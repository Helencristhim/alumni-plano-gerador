Capítulo 3: El Código

Quiero, Quieres, Quiere

querer + verbo

Descubre la Regla

Escucha y Observa

"Quiero correr en Barcelona."

"¿Qué quieres hacer?"

"Diego quiere visitar Brasil."

"No quiero trabajar el sábado."

¿Qué viene después de quiero: un verbo con -AR, -ER o -IR, o un verbo cambiado?

EstructuraEjemplo
yo quiero + verboQuiero visitar Barcelona.
tú quieres + verbo¿Quieres correr?
él / ella quiere + verboDiego quiere aprender portugués.
no quiero + verboNo quiero trabajar.

Como tener (tengo, tienes): quiero, quieres, quiere llevan IE con tú y él. Después: el verbo entero (correr, visitar).

Práctica
