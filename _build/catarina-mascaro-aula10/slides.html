The Code

Three ways to say the same thing

You should watch it. Seriously.
You could watch it, if you want.
You might like it. I am not sure.

It is a scale, not three rules

should = I am sure, do it · could = it is an option · might = maybe, I do not know you well enough. And after all three, the verb has no "to": should watch, never "should to watch".

The Code

Pick the strength

Strong

You should watch it.
You should definitely try it.
You have to see this.

Softer

You could try it.
You could always start with...
Maybe you could...

Not sure

You might like it.
It might be good.
It might be worth a try.

✗ You should to watch it  ·  ✓ You should watch it
✗ He shoulds try it  ·  ✓ He should try it (no S ever, on any of them)
Saying no politely: I don’t think you should... (softer than "you shouldn’t")
The Code

Soft should, hard SHOULD

youshould watch it

youcould start with

you SHOULD (arguing)

Only hit should when you are insisting. Otherwise it is a dip, not a hammer.

Did You Catch It?

How Bia convinced him

1. What was Sam’s first objection?
The poster looks terrible.
2. What did Bia suggest so it would take less time?
Skipping the first episode, which is the slowest.
3. Bia started with "you should". What did she change to, and did it work?
She went softer — "you could" and then "just give it a try". And yes: he agreed.

Three recommendations in one message
