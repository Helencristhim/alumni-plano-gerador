The Pattern Again

Which one is no longer true?

We used to do everything on paper.
We did not use to work with foreign clients.
In 2015 we took on our first foreign client.

used to = it happened often before, and it does not happen now

Negative: did not use to, with no d. Question: did you use to. One single moment with a date takes the past simple instead: we replaced the system in 2018.
