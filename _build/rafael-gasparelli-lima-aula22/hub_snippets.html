When Things Go Wrong

Get ready to solve problems. Key words: issue, complaint, damaged, shortage, root cause, backup plan, to fix, urgent. Structure: advice with should / shouldn't, and suggestions with Why don't we...? and How about + -ing?

Stage 1.1: Vocabulary Cards

Vocabulary

Eight words for the day something goes wrong. Tap Listen to hear each one.

Issue -- a problem that people need to talk about and solve
"We have an urgent issue with the last shipment."
Complaint -- a message from a client who is not happy
"The client sent a complaint this morning."
Damaged -- broken or hurt, so it is not in good condition
"Twenty boxes of mangoes were damaged."
Shortage -- when there is not enough of something
"There is a shortage of containers this month."
Root cause -- the real reason why a problem happened
"We should find the root cause first."
Backup plan -- a second plan you use if the first plan fails
"We need a backup plan for the next shipment."
To fix -- to repair something or to solve a problem
"The technicians can fix the machine on Thursday."
Urgent -- very important, and it needs action now
"The client wants an urgent answer."

Stage 1.3: Grammar in Context

GRAMMAR

Read the email from a consultant, then answer the questions.

Dear Rafael, thank you for your message about the complaint from Rotterdam. This is an urgent issue, so here is my advice. First, you should call the client today and say sorry. You shouldn't blame the port or the transport company in the first call. Then you should find the root cause: were the boxes damaged because the container was too warm?

I also have two suggestions. Why don't you send the temperature records to the client before Friday? And how about offering a partial refund for the damaged boxes? Finally, you should have a backup plan: if there is a shortage of containers, a second company can help. A problem that you fix quickly can make the client trust you more.

1. What should Rafael do first, according to the consultant?
A Send a partial refund.
B Call the client today and say sorry.
C Blame the transport company.
2. Why does the text say "how about offering" and not "how about offer"?
A Because after how about we use the -ing form.
B Because it is about the past.
C Because offer is an irregular verb.
3. What is the backup plan in the text?
A To call the port in Santos.
B To wait until next month.
C To use a second container company if there is a shortage.

Stage 1.4: Grammar Tip -- Advice and Suggestions

GRAMMAR

Use should for a good idea, shouldn't for a bad idea, and two easy forms to suggest something.

UseStructureExample
A good ideashould + base verbWe should check the records.
A bad ideashouldn’t + base verbYou shouldn’t blame the team.
Asking for adviceWhat should + we / I + base verb?What should we do first?
A suggestion (1)Why don’t we / you + base verb?Why don’t we call the client?
A suggestion (2)How about + verb-ing?How about sending an email?

Never: we should to call · he shoulds check · how about send · why don’t we calling

Stage 4: Situational Quiz

Quiz

Choose what a director would say in each situation.

A client complains about damaged boxes. You give advice to your team:
A "We should to call the client today."
B "We should call the client today."
C "We shoulds call the client today."
Your team wants to wait one week before answering. You say:
A "We shouldn't wait too long. The client wants an answer today."
B "We don't should wait too long."
C "We shouldn't to wait too long."
A machine stopped at the plant. You make a suggestion:
A "How about use the stock in the other warehouse?"
B "Why don't we using the stock in the other warehouse?"
C "Why don't we use the stock in the other warehouse?"
You want to plan for the next problem. You say:
A "How about preparing a backup plan for the next shipment?"
B "How about prepare a backup plan?"
C "We should preparing a backup plan."
