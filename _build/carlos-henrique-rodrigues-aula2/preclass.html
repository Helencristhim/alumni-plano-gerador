Etapa 1.4: Grammar Tip -- There is / There are (tem, há)

GRAMMAR

Em português dizemos "tem um lago". Em inglês, para lugar, nunca usamos "have": usamos there is / there are. / To describe a place, use there is / there are, never "have".

Uso / UseEstrutura / PatternExemplo / Example
Uma coisa / One thingthere is + a / anThere is a lake. (Tem um lago.)
Várias coisas / Many thingsthere are + pluralThere are mountains. (Tem montanhas.)
Negativa / Negativethere is not / there are noThere are no Brazilian restaurants. (Não tem restaurante brasileiro.)
Pergunta / QuestionIs there...? / Are there...?Is there a station? (Tem estação?)
Resposta curta / Short answerYes, there is. / No, there is not.Is there a lake? Yes, there is. (Tem, sim.)
Ideia-chave / Key idea"Tem" em português vira there is / there are quando falamos de um lugar. "Have a lake" não existe em inglês. / "Tem" becomes there is / there are for places. "Have a lake" does not exist in English.
