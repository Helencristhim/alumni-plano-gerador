Uma janela de mudança técnica, ao vivo, numa call com a Índia. Palavras-chave: server, turn off, turn on, update, test, problem. Estrutura: presente contínuo (am / is / are + -ing). Curto: 15 minutos de manhã.

Etapa 1.3: Grammar in Context

GRAMMAR

Leia o texto em voz alta, devagar, e depois responda as perguntas.

It is Saturday night. The change window is open. Raj is turning off the old service in India. His team is moving the traffic to server B.

In São Paulo, Ender's team is testing the payments. "Are the payments working?" "Yes, they are. But one store is having a problem."

The store isn't using the new server. Ender fixes it. Now Raj is turning on the new update.

1. O que a equipe do Ender está fazendo? (What is Ender's team doing?)
A Desligando o serviço antigo na Índia, com o Raj. (Turning off the old service.)
B Testando os pagamentos. (Testing the payments.)
C Dormindo, porque é sábado. (Sleeping.)
2. Por que o texto diz "is testing" e não "tests"?
A Porque está acontecendo agora. (It is happening now.)
B Porque a equipe testa toda segunda-feira de manhã. (Every Monday.)
C Porque é passado. (Because it is the past.)
3. Como se diz "A loja não está usando o servidor novo"?
A "The store don't using the new server, it uses the old."
B "The store not using the new server."
C "The store isn't using the new server."

Etapa 1.4: Grammar Tip -- Presente contínuo (am / is / are + -ing)

GRAMMAR

Para o que está acontecendo AGORA, use o verbo to be + verbo com -ing. É o "estou fazendo" do português. / For actions happening now: am / is / are + verb-ing.

Uso / UseEstrutura / PatternExemplo / Example
Eu / Iam + -ingI am testing. (Estou testando.)
Ele, ela / He, sheis + -ingRaj is turning off the service. (O Raj está desligando o serviço.)
Nós, eles / We, theyare + -ingWe are moving the traffic. (Estamos movendo o tráfego.)
Negativa / Negativeam not / isn’t / aren’t + -ingIt isn’t working. (Não está funcionando.)
Pergunta / QuestionAm / Is / Are ... -ing?Are the payments working? (Os pagamentos estão funcionando?)
Sempre x agora / Always x nowtest x am testingI test every Monday. Now I am testing. (Testo toda segunda. Agora estou testando.)
Ideia-chave / Key ideaO verbo to be NÃO pode sumir: "we testing" está errado, o certo é "we are testing". Pense no português: "nós ESTAMOS testando". / The verb to be never disappears: we ARE testing.
