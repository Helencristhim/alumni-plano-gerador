Chapter 4: The Code

I Want to Go, I’d Like to See

Two ways to talk about wishes

Grammar Discovery

Four Sentences About a Trip

"I want to see the canals in Amsterdam."

"I would like to visit Edinburgh Castle."

"She wants to rent a bike."

"Would you like to see the northern lights?"

Look at the blue words. After want and would like comes to + the simple verb. Want takes -s with she; would like never changes. Now the red word: the question starts with would.

JobFormExample
A strong wishwant to + verbI want to see the canals.
With he / shewants to + verbShe wants to rent a bike.
A polite wishwould like to + verb (I’d like to)I’d like to visit the castle.
QuestionWould you like to + verb? / Do you want to + verb?Would you like to come?
Negativedon’t want to / wouldn’t like toI don’t want to go in August.
The trapalways to before the verbNot I want go. Say I want to go.

In one line: want to and would like to + the simple verb; would like is softer and never takes -s.
