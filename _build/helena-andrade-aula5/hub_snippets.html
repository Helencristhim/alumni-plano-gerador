Vocabulary

Incident report -- the official written account of something that went wrong on board
"Near misses rarely reach an incident report at all."
Near miss -- an event that could have caused harm but did not
"The near-miss data began to tell another story."
Master -- the officer in command of a merchant ship, whatever the ship's size
"The master was ashore on the afternoon in question."
Flag state -- the country in which a ship is registered and whose law she carries
"Near misses are not reported to a flag state."
Manning -- the number and the qualifications of the crew a ship actually carries
"They cluster around exactly the manning arrangements the certificates call adequate."
Watchkeeping -- the duty of standing a watch, keeping the ship safe for a set period
"The certificate is supposed to guarantee the watchkeeping behind it."
STCW -- the IMO convention that sets training and certification standards for seafarers
"Under STCW every officer must hold a certificate that is periodically revalidated."
ISM Code -- the international standard for safe management and pollution prevention on board
"Under the ISM Code every company must establish procedures for its own hazards."
Muster station -- the place each person must go to when the emergency signal sounds
"The muster station list had not been updated since the last crew change."
Lifeboat drill -- the practice exercise in which the crew rehearses abandoning ship
"What is missing is not the lifeboat but the lifeboat drill."

Stage 1.3: Grammar in Context

GRAMMAR

Read the passage, then answer the questions about how it is written.

Rarely is a maritime casualty caused by a single failure. Hardly had the industry finished congratulating itself on falling figures when the near-miss data began to tell another story.

Not only does under-manning increase fatigue, but it also removes the second person whose whole function is to notice what the first has missed. Only when the drill is treated as an operation rather than as a record does the paperwork begin to describe the ship. Not until a program had beaten a reigning world champion at chess did the public accept that a machine could reason at all.

1. Rarely is a maritime casualty caused by a single failure. What does the sentence claim?
A That a casualty never has only one cause.
B That single-cause casualties are unusual, but they exist.
C That the writer has no data on causes.
2. Why is it Not only does under-manning increase fatigue and not Not only under-manning increases fatigue?
A Because the negative phrase at the front pulls the auxiliary in front of the subject.
B Because under-manning is plural.
C Because not only can never be followed by a noun.
3. In Only when the drill is treated as an operation does the paperwork begin..., where does the inversion happen?
A Inside the only when clause.
B In the main clause, after the only when clause has finished.
C In both halves of the sentence.

Stage 1.4: Grammar Tip -- Inversion After Negative and Limiting Adverbials

GRAMMAR

Formal prose puts the emphatic word first and pays for it by moving the auxiliary in front of the subject. Nothing about the facts changes -- but the degree does, and the degree is what the wrong option attacks.

FormWhat it doesExample
negative adverb firstrarely, seldom, never, little, at no time: the auxiliary jumps in front of the subjectRarely is a casualty caused by one failure.
hardly / scarcely / no sooner ... whenone thing had only just happened when the next didHardly had they finished when the data changed.
not only ... but alsothe inversion happens in the FIRST half only; the second half is ordinaryNot only does it increase fatigue, but it also removes...
only when / only after / not untilthe inversion lands on the MAIN clause, never inside the only-clauseOnly when the drill is real does the paperwork describe the ship.
The reading trapinversion is EMPHASIS, not negation. Rarely is a casualty caused by a single failure does not mean never. Turning rarely into never, or hardly into not at all, is the standard wrong option -- and it is wrong by degree, not by topic.

Inversion tells you the writer is leaning on something. It never tells you the thing is absolute. Every question built on an inverted sentence tests whether you read the degree or only the direction.
