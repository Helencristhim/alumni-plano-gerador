Lesson 20 -- Pre-class

The Security Questionnaire -- The Form the Customer Sends

The questionnaire a European customer sends before any contract: what must be done with the data, and how to answer it yourself. Key words: to encrypt, a backup, to store, two-factor authentication, permissions, an audit, a vulnerability, to retain, a certification, an incident. Structure: modal passive (must be, can be, should be, will be + past participle).

Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example. Tap Listen to hear it.

To encrypt -- to change data into a secret code so other people cannot read it
"All customer data must be encrypted before it leaves the server."
A backup -- a copy of data that you keep in case the original is lost
"We make a backup of every database each night."
To store -- to keep data in a place, for example on a server
"Our customers want their data to be stored in Europe."
Two-factor authentication -- logging in with a password and a second proof, like a code on your phone
"Two-factor authentication is required for every user."
Permissions -- what each user is allowed to see or do in a system
"When someone leaves, their permissions are removed on the same day."
An audit -- an official check of a company's systems by an independent person
"Our last external audit was in March."
A vulnerability -- a weak point that an attacker could use
"The team found a vulnerability and fixed it in two days."
To retain -- to keep something for a period of time, and not delete it
"We retain invoice data for five years, as the law requires."
A certification -- an official document that shows a company meets a standard
"Our ISO 27001 certification is attached to this email."
An incident -- an event where something goes wrong with security
"Any incident is reported to the customer within 24 hours."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text, then answer the questions.

A security questionnaire talks about rules for data, not about people. That is why it uses the passive with a modal verb. Customer data must be stored in the EU. Every file must be encrypted. Nobody says who does it, because it does not matter: what matters is the rule.

The modal tells you how strong the rule is. Must be means there is no choice. Should be is a recommendation: backups should be tested every quarter. Can be says what is possible: permissions can be removed in one hour. Cannot be says what is not accepted: data cannot be stored outside the EU.

When you answer, you use the same structure. A good answer is short and specific: our data is stored in Frankfurt. When something is not ready yet, you make an honest promise with a date: the audit report will be sent by Friday.

The structure is always the same: the modal, then be, then the past participle. Brazilian speakers often forget one of the three parts and say must encrypted or must be encrypt.

1. Which sentence is a recommendation, not an obligation?
A "Data must be encrypted."
B "Backups should be tested every quarter."
C "Data cannot be stored outside the EU, and suppliers who do it lose the deal."
2. Which sentence is correct?
A "Permissions can removed in one hour by the IT team."
B "Permissions can be remove in one hour."
C "Permissions can be removed in one hour."
3. Why doesn't the questionnaire say who encrypts the data?
A Because the rule about the data matters, not the person who does it.
B Because the customer does not know the names of the supplier's engineers and does not want to ask.
C Because the passive is more polite than the active in every situation.

Stage 1.4: Grammar Tip -- The Modal Passive

GRAMMAR

Modal + be + past participle. The thing the form asks about comes first.

FormMeaningExample
must be + participleobligationAll data must be encrypted.
must not be + participlenot allowedPasswords must not be shared.
should be + participlerecommendationBackups should be tested every quarter.
can be + participlepossiblePermissions can be removed in one hour.
cannot be + participlenot possible / not acceptedData cannot be stored outside the EU.
will be + participlepromiseThe report will be sent by Friday.
Questionmodal + subject + be + participleHow often should backups be tested?

Never: must encrypted · must be encrypt · can removed · will send (when you mean will be sent)
