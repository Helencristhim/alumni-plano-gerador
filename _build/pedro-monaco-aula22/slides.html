Chapter 3: The Code

When the Rule Matters, the Order Changes

Not only, never, rarely, only when, under no circumstances

Grammar Discovery

Listen and Notice

"Under no circumstances should we offer cash to an official."

"Not only does the law apply to the US office; it can also reach the parent company."

"Rarely do companies think about bribery first."

"Only when the agent has been checked will we sign the contract."

None of these sentences is a question. Look at the orange words: what comes first, the subject or the verb? And what do the words at the start of each sentence have in common?

PatternWhat it doesExample
Under no circumstances / On no account + auxiliary + subjectA rule with zero exceptions. Typical of policies and contracts."Under no circumstances should employees accept cash."
Not only + auxiliary + subject ..., (but) ... alsoAdds a second, bigger point. Only the FIRST part is inverted."Not only is it illegal; it is also bad business."
Never / Rarely / Seldom + auxiliary + subjectHow often something happens, said with force."Rarely do auditors accept a vague invoice."
Only when / Only if / Only after + clause, + auxiliary + subjectThe inversion comes in the SECOND clause, after the condition."Only when the check is complete will we sign."
Nor / Neither + auxiliary + subjectAdds another negative point."The FCPA allows it. Brazilian law does not, nor does the UK law."
No auxiliary in the normal sentence?Use do, does or did, as in a question."We rarely check. → Rarely do we check."

A negative or limiting word goes to the front, and the auxiliary jumps before the subject. This is formal, written English: policies, contracts, speeches. In a relaxed conversation, the normal order sounds more natural.

Meaning

Same Rule, More Weight

Normal order first, then the emphatic version

"We never accept cash from suppliers."

"Never do we accept cash from suppliers."

A fact, said with full force. Typical of a code of conduct.

"The law applies to the office, and it can also reach the parent company."

"Not only does the law apply to the office; it can also reach the parent company."

The listener is waiting for the second, bigger point.

"You should not invite an official in any situation while a decision is pending."

"Under no circumstances should you invite an official while a decision is pending."

No exceptions, and everybody can see it.

"We will sign the contract only when the check is complete."

"Only when the check is complete will we sign the contract."

The condition comes first, so nobody can miss it.
