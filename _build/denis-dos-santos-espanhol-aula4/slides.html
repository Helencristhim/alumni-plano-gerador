"¿Recibiste mi status report?"

¿Estas acciones pasan ahora o ya pasaron? ¿Cómo termina el verbo con yo? ¿Y con él o ella?

Persona-ar: terminar-er / -ir: recibir
yoterminérecibí
túterminasterecibiste
él, ella, ustedterminórecibió
nosotrosterminamosrecibimos
ellos, ellas, ustedesterminaronrecibieron

Con yo, la terminación es -é o -í. Con él o ella, es -ó o -ió. Con ellos, es -aron o -ieron.

El Acento

Termino o Terminó

termino (hoy, yo)

Hoy termino el informe.

Siempre envío el informe el viernes.

terminó (ayer, él o ella)

Ayer Javier terminó el informe.

Mariana envió el informe el viernes.

Terminamos sirve para hoy y para ayer: usa ayer, el lunes o la semana pasada.
