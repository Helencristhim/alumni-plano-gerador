Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each expression and read the example. Tap Listen to hear it.

Touch base -- to contact someone briefly to check how things are going
"Let me touch base with the client before Friday."
Get the ball rolling -- to start a project or an activity
"We signed the contract, so let's get the ball rolling."
Back to the drawing board -- to start again because the first plan did not work
"The buyer said no, so it is back to the drawing board."
Keep in the loop -- to give someone regular updates so they always know what is happening
"Please keep me in the loop about the shipment."
Hit the ground running -- to start a new job or project quickly and well, with no delay
"Our new trader hit the ground running in his first week."
Ahead of the curve -- more modern or more advanced than other people or companies
"Our traceability system keeps us ahead of the curve."
Cut corners -- to do something badly or cheaply to save time or money
"We never cut corners on quality control."
Win-win -- good for both sides of a deal
"A long contract is a win-win for the farm and for us."
Think outside the box -- to think in a new and creative way
"We need to think outside the box to reach new buyers."
Call it a day -- to stop working for the day
"It's eight o'clock. Let's call it a day."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text, then answer the questions.

Walyson has been working at Sucafina for five years. This year, his team has been preparing a new traceability system for the growers. They started in March, and the project is not finished: they are still working on it. That is why we use the present perfect continuous: have / has + been + verb-ing.

To say how long, use for with a period (for five years, for three months) and since with a starting point (since March, since 2020). Portuguese uses the present tense for this idea, so Brazilians often say "I work here for five years". In English, the correct sentence is "I have been working here for five years."

Some verbs describe states, not actions: know, like, own, believe. They do not take -ing. We say "I have known Clara for two years", not "I have been knowing".

1. Which sentence is correct?
A I am working at Sucafina since 2020, in the Santos office, with the trading team.
B I have been working at Sucafina since 2020.
C I work at Sucafina since 2020.
2. Why do we say "I have known Clara for two years" and not "I have been knowing"?
A Because Clara is a client and not a colleague from the same office in Santos.
B Because know is a state verb, and state verbs do not take -ing.
C Because the sentence is about the past and the action is completely finished.
3. Which word completes the sentence: "We have been waiting ___ Monday"?
A since
B for, because we are talking about a long period of time
C during

Stage 1.4: Grammar Tip -- The Present Perfect Continuous

GRAMMAR

An action that started in the past and is still going: have / has + been + verb-ing.

FormStructureExample
Affirmativehave / has + been + -ingWe have been working on it since March.
Negativehaven’t / hasn’t + been + -ingHe hasn’t been sleeping well.
QuestionHow long + have / has + subject + been + -ing?How long have you been waiting?
for / sincefor + period · since + start pointfor two weeks · since Monday
State verbspresent perfect simpleI have known her for years.

Remember: idioms keep their exact words. Say touch base, never touch the base.

Stage 2: Put the Project Update in Order

Order

You are giving your director an update. Put the sentences in a clear order: the project, the start, the problem, the new plan, the result and the next step.

?"Our team has been working on the traceability project since March."
?"First, we touched base with forty growers to get the ball rolling."
?"Our first plan was too expensive, so we went back to the drawing board."
?"Since then, we have been testing a simpler system with ten farms."
?"The new system is a win-win for the growers and for our buyers."
?"I will keep you in the loop about the results next month."
