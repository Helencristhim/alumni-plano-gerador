InfinitivoGerundioEjemplo
-ar: probarprobandoEstamos probando.
-er / -ir: hacer, escribirhaciendo, escribiendoEstoy escribiendo el correo.
leerleyendoEstá leyendo el informe.
pedir, seguirpidiendo, siguiendoEstá pidiendo ayuda.
seguir + gerundiosigo revisandoLa acción continúa.

estar (estoy, estás, está, estamos, están) + gerundio = una acción de ahora. Para la rutina, usa el presente: «Hago pruebas todos los meses».
