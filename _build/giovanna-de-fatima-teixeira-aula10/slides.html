Chapter 3: The Pattern

Same Meaning, Different Sound

I want · I would like

Grammar Discovery

Listen and Notice

I want a coffee.
I would like a coffee, please.
Would you like a table for six?
I would like to see the menu.

The first two mean the same thing. Which one would you say to a client?

StructureWhenExemplo
I want + coisadirect, and it sounds hardI want a coffee.
I would like + coisathe polite version, always safeI would like a coffee, please.
I would like to + verbowhen you want to DO somethingI would like to see the menu.
Would you like ...?how you offer somethingWould you like a coffee?
CuidadoCom COISA nao entra "to": I would like a coffee, nunca "I would like to a coffee". Com VERBO entra: I would like to see. Forma curta: I would like = I'd like. E o "please" no fim custa nada e muda tudo.
