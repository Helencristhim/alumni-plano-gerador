Lesson 04 -- Pre-class

What If -- Real and Hypothetical Scenarios

Answering the hardest question in an executive interview. Key words: to restructure, to leverage, to allocate, sustainable, scalable, headcount, turnaround, to prioritize. Structure: the first conditional for real plans and the second conditional for imaginary situations.

Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example. Tap Listen to hear it.

To restructure -- to change the way a team or a system is organized
"If the board approved it, we would restructure the pricing team."
To leverage -- to use something you already have to get a bigger result
"We leverage the data we already collect in every store."
To allocate -- to decide where money, people or time will go
"If we had more budget, we would allocate it to analytics."
Headcount -- the number of people a company employs
"Option A does not need extra headcount."
Sustainable -- able to continue at the same level for a long time
"One good quarter is not a sustainable result."
Scalable -- able to grow to a much bigger size without breaking
"We would gain a scalable system, not a one-year answer."
Turnaround -- a change that takes a company from losing to winning
"The turnaround would not be visible before the fourth quarter."
To prioritize -- to decide what comes first when you cannot do everything
"If I had one quarter, I would prioritize the six weak categories."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text and answer the questions.

This memo presents two options for the southern region. If we hold current prices, the margin will stay at last year's level, and we will not need extra headcount. However, if the competitor cuts prices in March, we will lose volume in six categories. If the board approved the second option, we would restructure the pricing team and rebuild the model at SKU level. The turnaround would not be visible before the fourth quarter, but we would gain a scalable system. If we had a bigger data team today, this memo would offer three options instead of two.

1. Why does the memo say "if we hold current prices, the margin will stay"?
A It is a real situation that the company can choose, so it takes "will".
B It is imaginary and impossible, so it takes "will".
C It already happened last year, so it takes "will".
2. Why is "if we had a bigger data team, this memo would offer three options" in the second conditional?
A The company does not have a bigger data team, so the situation is imaginary.
B The data team will grow next month, so the situation is a plan.
C Memos always use "would" instead of "will".
3. Which sentence is correct?
A "If we will restructure the team, we would need four analysts."
B "If we restructured the team, we would need four analysts."
C "If we restructured the team, we will need four analysts."

Stage 1.4: Grammar Tip -- First and Second Conditional

GRAMMAR

One question decides the form: can this really happen?

TypeFormUse and example
First conditionalIf + present simple, will + base verbA real plan, warning or promise. "If we cut prices, we will lose margin."
Second conditionalIf + past simple, would + base verbAn imaginary situation. "If I were the VP, I would restructure the team."
If I werewere, for every personIn the second conditional, say "if I were", "if he were", never "if I was".
Two rules to rememberWill never goes after if. And never mix the two: "if we had" always takes would, never will.
