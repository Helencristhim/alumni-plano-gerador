Chapter 3: The Code

Two Kinds of If

If we do it, we will... · If I were you, I would...

Grammar Discovery

Read and Notice

"If we cut prices in March, we will lose margin."

"If the board approves it, we will restructure the team."

"If I were the VP of Pricing, I would restructure the team."

"If we had a bigger data team, we would offer three options."

Two sentences use will and two use would. Which pair is about something that can really happen?

TypeFormUse
First conditionalIf + present simple, will + base verbA real situation that can happen. A plan, a warning, a promise.
Second conditionalIf + past simple, would + base verbAn imaginary situation. Not true now, or unlikely.
If I werewere, for every personIn the second conditional, say if I were and if he were, never if I was.
Word orderBoth halves can change places: We would restructure the team if I were the VP. The comma disappears when if comes second.

One question decides it: can this really happen? If yes, use will. If it is imagination, use would.

Common Mistake

Right vs Wrong

"If we will cut prices, we will lose margin."
"If we cut prices, we will lose margin."
"If I was the VP of Pricing, I would restructure the team."
"If I were the VP of Pricing, I would restructure the team."
"If we had more budget, we will allocate it to analytics."
"If we had more budget, we would allocate it to analytics."

Will never goes after if. Use were for every person in the second conditional, and never mix had with will in the same sentence.

Detail

Disagree Without a Fight

The same "would" makes a hard opinion sound professional

Direct: "You are wrong." → Professional: "I ___would see it differently."
Direct: "That is a bad idea." → Professional: "I ___would be careful with that."
Direct: "Your number is wrong." → Professional: "I ___would question that number."
Direct: "Do it my way." → Professional: "If it ___were my decision, I would start with the data."

Opening the Case

0:000:00

The right answer. She is looking for your reasoning.

What the company actually did.

Two people who disagreed, and both were right about something.
