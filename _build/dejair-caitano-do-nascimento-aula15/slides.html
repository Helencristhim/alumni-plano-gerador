Chapter 3: The Code

A Condition and a Promise

if + present, will or can + verb

Grammar Discovery

Two Halves, One Promise

If you send me your email, I'll forward you the paper tonight.
If we collaborate, we can submit to a bigger journal.
If I don't hear from you by Friday, I'll send you a reminder.
If I don't understand a question, I ask the speaker to repeat it.
Click to reveal the rule
After if we use the present simple, even when we talk about the future: if you send, never if you will send. In the other half we use will (a promise or a result) or can (a possibility or an offer) + the base verb: I'll forward, we can submit. This is the first conditional: a real situation that is likely to happen. The if half can come first (with a comma) or second (no comma): I'll send you a reminder if I don't hear from you. Sentence 4 is different: present in both halves, because it is always true for you — a habit, not a promise.
