Chapter 3: The If Code

If This, Then That

If + present · will / can + verb

Grammar Discovery

Listen and Notice

"If a product has a geographic indication, it gets more protection."

"If producers meet the criteria, they receive the certification."

"If we confirm the partnership this week, we will present it in Milan."

"If you are interested, I can send you more information."

What do the orange words have in common? Which verb comes after "if"? Which sentences are always true, and which are about the future?

PatternMeaningExample
If + present, presentalways true (a fact)If a product has a GI, it gets more protection.
If + present, will + verba real possibility in the futureIf we confirm this week, we will present it in Milan.
If + present, can + verban offer that depends on a conditionIf you are interested, I can send you more information.
NOT: if + willnever use will after ifIf we confirm (not: if we will confirm)

After if, always use the present. You can start with the result: "We will present it in Milan if we confirm this week." Use a comma when "if" comes first.

Chapter 4: The Negotiation

Meeting Halfway

Paolo asks; Flavia proposes

Dialogue

The Negotiation

P
Thank you for your proposal, Flavia. We like it. What are the next steps?
F
If you confirm the partnership this week, we will organize a visit to our producers in March.
P
March is difficult for us. Is April feasible?
F
April works. That is a good compromise. Would it be possible to sign the agreement in May?
P
Yes, but we have one condition: the terms must be in English and Italian.
F
We would be happy to do that. If you send us your model, I can prepare the document.
P
Perfect. This is good for our mutual interests. Thank you for meeting us halfway.
F
Thank you, Paolo. So, the next step is your model. If that works for you, I can send a summary today.
