Chapter 3: The Code

If We Had, We Would Have

How to talk about a past that did not happen

Grammar Discovery

Real Past or Imagined Past?

"If we had checked the data in January, we wouldn’t have needed three extra weeks."

"If Tom hadn’t reported it early, it would have been a crisis."

"If we had listened to him, the overrun would have been much smaller."

"We could have saved three weeks if we had tested earlier."

None of these things happened. We did not check the data in January, and we did need three extra weeks. Look at the blue verbs after if and the red verbs in the result. What do they have in common?

PartFormExample
The imagined conditionIf + had + past participleIf we had checked the data, ...
The imagined resultwould have + past participle... we would have saved three weeks.
Negativehadn’t ... / wouldn’t have ...If he hadn’t reported it, ...
A possible resultcould have / might have + past participleWe could have saved money.
Orderresult first = no commaWe would have saved time if we had tested earlier.
The trapnever would in the if partNot If we would have checked. Say If we had checked.

In one line: If + had + past participle, would / could have + past participle -- for a past that did not happen.

Chapter 4: The Review

After Go-Live

One call, two recordings, one lessons-learned log

Dialogue

The Lessons Learned

C
Diana, the bridge went live on March first, and payroll ran without a single error. Now let's do the post-mortem.
D
Good. In hindsight, what was our biggest oversight?
C
The old data. If we had checked it in January, we wouldn't have needed three extra weeks of testing.
D
True, but nobody could foresee how bad it was. Were there any warning signs?
C
One. Tom saw some strange numbers in December. If we had listened to him then, the overrun would have been much smaller.
D
So part of it was avoidable. And what would have happened if he hadn't reported it early?
C
In retrospect, it would have been a crisis. The committee would have lost trust in the whole integration.
D
Then his honesty paid off. Let's write that down as our first lesson.
Comprehension

About Diana

1. What is Diana’s first question in the post-mortem?
In hindsight, what was the biggest oversight?
2. Does Diana think the team could foresee the data problem?
No. She says nobody could foresee how bad it was.
3. What does Diana want to write down as the first lesson?
That Tom’s honesty paid off: reporting the problem early prevented a crisis.
Listening 1 · The Expert

Not a Trial

A project management expert explains how to run a post-mortem. Sound first — no text.

1. According to the expert, what is a post-mortem NOT?
A trial: nobody is there to find a guilty person.
2. If you could have foreseen the problem, what was it, and what do you need?
An oversight, and you need a new process.
3. How should a post-mortem finish?
With three lessons learned, each one with an owner.
Listening 2 · The Voicemail

A Message from Tom

Tom Reyes calls Carlos after the first payday. Sound first — no text.

1. What did the March payroll report show?
Every salary was correct.
2. What would have happened without the extra testing?
About four hundred people would have received the wrong salary.
3. What does Tom suggest for the next project?
Check the old data before signing the plan, not after.
