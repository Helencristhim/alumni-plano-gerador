Chapter 3 -- The Code

Grammar Discovery

An opinion needs a reason

Grammar Discovery

Listen and Notice

One orange word introduces a reason. The other introduces a result. Which is which?

"Episode one is boring, because nothing happens."

"Episode two is exciting, because she finds an old letter."

"The season is only eight episodes, so it is a perfect weekend."

"I hate spoilers, so I will not tell you the ending."

Grammar Rule

Opinion + because / so

WordWhat comes after itExample
becausethe reasonIt is boring, because nothing happens.
sothe resultNothing happens, so it is boring.
Opinion wordsabout the thing, not the personThe plot is exciting. The episode is boring.
Soften ita little / a bit + adjectiveIt is a little boring at the start.
RecommendYou should + base verbYou should watch it, because it is short.

Key idea: because and so are mirrors. "It is boring, because nothing happens" and "Nothing happens, so it is boring" say the same thing in the opposite order. Never use both in one sentence.

0 / 4 errors found

"Episode one is boring, so nothing happens."

"The season is short, because I finished it in one weekend."
