Stage 1.3: Grammar in Context

GRAMMAR

Read the text and answer the questions.

A server hears the same three sentences all evening. "I would like a table for two." "I would like some water." "I would like to see the menu." Look at what changes and what does not. Would like never changes: it is the polite way to say what you want, and it works for every person. What changes is the word right after it. A table is one thing you can count, so it takes a. Water is not something you count, so it takes some. And when what you want is an action, not a thing, you need to before the verb. Say "I want" instead and the sentence is still correct English, but it sounds like an order, not a request.

1. Why do we say "some water" and not "a water"?
A Because water is always plural in English.
B Because water is uncountable, so it cannot take a or an.
C Because water is a drink and drinks never take a.
2. Which sentence is correct?
A "I would like see the menu, please."
B "I would like to see the menu, please."
C "I would like to a menu, please."
3. According to the text, what is the difference between "I want" and "I would like"?
A "I want" is wrong English in a restaurant.
B They mean different things.
C Both are correct, but "I want" sounds like an order and "I would like" sounds like a request.

Stage 1.4: Grammar Tip -- Would like + countable and uncountable

GRAMMAR

The word you put after would like depends on whether you can count what you are asking for.

You can count itYou cannot count itAn action
I would like a table.I would like some water.I would like to see the menu.
I would like an appetizer.I would like some rice.I would like to order now.
I would like two main courses.I would like some bread.I would like to pay by card.

Questions use the same shape: "Would you like a side dish?" The short answers are "Yes, please" and "No, thank you". And if you really need a number for something uncountable, count the container: "two glasses of water", "three cups of coffee".
