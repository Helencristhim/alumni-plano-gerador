Lesson 07 -- Pre-class

How It Actually Works -- Explaining the Integration

The finance director asks how it works and there is no engineer on the call. Ninety seconds, five steps, and not one word that needs a second explanation. Key words: to trigger, a field, to sync, to flag, a batch, real time, to roll back, to trace, an alert, a connection point. Structure: when, if, once and as soon as with the present.

Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example. Tap Listen to hear it.

To trigger -- to make something start automatically
"The arrival of the file triggers the whole process. Nobody presses anything."
A field -- one piece of information in a record, like the date or the amount
"Nine fields are mandatory. If one of them is empty, nothing moves."
To sync -- to make two systems hold the same information
"The two systems sync overnight, so Monday morning they agree."
To flag -- to mark something so that a person looks at it
"The system does not reject it. It flags it, and a human decides."
A batch -- a group of items processed together, not one by one
"It runs in one batch every night, not one invoice at a time."
Real time -- happening immediately, with no waiting
"It is not real time. It is once a night, and for them that is enough."
To roll back -- to undo a change and return to the previous state
"If the night run fails, we roll back and nobody sees anything."
To trace -- to follow something back to where it came from
"Every invoice can be traced from the supplier to the payment."
An alert -- an automatic message that tells somebody something happened
"One alert, to one person, with the invoice number in it."
A connection point -- the point where one system connects to another to exchange data
"There is one connection point. Everything else sits behind it."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text, then answer the questions.

Somebody who understands a system can describe it in ordinary words. Somebody who does not hides inside the jargon, and the person listening can always tell which one is happening. So the explanation is five steps, one verb each, and no word that needs a second explanation.

Here it is. When a supplier file arrives, that triggers the run; nobody presses anything. The system reads nine fields, and if one of them is missing it flags the invoice instead of rejecting it, because a person should decide and not a system. One alert then goes to one named person, with the invoice number in it. Once that person approves it, the two systems sync. And every invoice can be traced from the supplier to the payment, which is the step people ask about twice.

Look at the verbs. Every one of them is in the present, on both sides of every sentence, because none of this is about tomorrow: it is what happens every single time. That is why when a file will arrive is wrong in English even though the Portuguese sentence puts the future there. After when, if, once and as soon as, English simply stays in the present.

Two more things, and both of them sell better than any feature. It is not real time: it runs once a night, in one batch, and saying so early makes everything else believable. And as soon as a run fails, the whole batch is rolled back, so nothing half-finished ever reaches their ERP. Nobody asks how it works. They ask what happens when it does not.

1. Why is "When a file will arrive, the system checks it" wrong?
A Because will is too formal for a technical explanation.
B Because after when, if, once and as soon as, English stays in the present, even when the meaning is about the future.
C Because arrive is an irregular verb.
2. Why does the text say the system flags the invoice instead of rejecting it?
A Because a person should decide, not the system. Flagging sends it to somebody; rejecting it just sends it back.
B Because rejecting a file is technically impossible.
C Because flagged invoices are paid faster.
3. The text says admitting it is not real time sells better than any feature. Why?
A Because customers prefer slow systems.
B Because real time is a word nobody understands.
C Because it will be found out at the first month-end anyway, and saying it early makes everything else you say believable.

Stage 1.4: Grammar Tip -- When, If, Once and As Soon As

GRAMMAR

Describing a process is present on both sides, and there is no future in it anywhere.

JobFormExample
Something that always happenswhen / if + present, presentWhen a file arrives, the system checks it.
Never the future after these wordswhen, if, once, as soon as, after, before, untilNot when a file will arrive
Order of the stepsfirst, then, after that, finallyFirst the file arrives. Then it is checked.
One step ends, the next startsonce / as soon asOnce it is approved, the systems sync.
The clause can come secondthen no commaThe system checks it when a file arrives.
Third person keeps its -son both sides of the sentenceOnce the team approves it, the run starts.
No then after whenthe comma already does thatNot When it arrives, then the system checks
When vs ifwhen = it always happens · if = it may notWhen the file arrives · If a field is missing

Never: When a file will arrive · When the file arrives, then the system checks · when arrives the file · Once the team approve it · As soon as the run will fail

Stage 4: Situational Quiz

Quiz

Choose the answer a real speaker would give.

You want to say that the process starts by itself. You say:
A "When a file will arrive, the run starts."
B "When a file arrives, that triggers the run. Nobody presses anything."
C "When arrives the file, then the run starts."
They ask whether the data is updated immediately. It is not. You say:
A "Yes, everything is in real time."
B "No. It runs once a night, in one batch, and for most customers that turns out to be enough."
C "That depends on many technical factors we can discuss later."
They ask what happens on a bad morning. You say:
A "If the run fails, we roll back the batch, so nothing half-finished reaches your ERP, and one alert goes to your named person."
B "It does not fail. In three years we never had a problem."
C "Our support team is available and very responsive."
A non-technical buyer stops you and asks what a field is. The good answer is:
A "It is a data structure element in the payload schema."
B "One piece of information on the invoice, like the date or the amount."
C "It is a technical thing, your IT team will understand."
