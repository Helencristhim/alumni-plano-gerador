Lesson 06 -- Pre-class

This Week’s Status Update -- What Is Happening Now

Every week somebody asks: where are we with the project? Key words: a status update, on track, behind schedule, a launch, a trial, an issue, a priority, to work on. Structure: present continuous for things in progress.

Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example. Tap Listen to hear it.

A status update -- a short report on how a project is going
"I send a status update to the team every Wednesday."
On track -- going as planned, with no delay
"The trial is on track for October."
Behind schedule -- later than the plan
"The launch is two weeks behind schedule."
A launch -- the moment a new product starts to be sold
"The launch of the new adhesive is in November."
A trial -- a test of a product in real conditions
"The customer is running a trial at the factory."
An issue -- a problem that you need to solve
"We have an issue with the packaging."
A priority -- the most important thing to do first
"Our priority this week is the trial."
To work on -- to spend time doing or improving something
"We are working on the new label this week."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text, then answer the questions.

It is Wednesday, and Anna is writing the weekly status update. A customer in France is running a trial of the new adhesive. The trial is on track.

But there is an issue: the supplier is changing the packaging, so the launch is two weeks behind schedule. Anna is working on a new plan, and she is talking to the supplier every day this week.

Fernanda reads the update. Her priority this week is the trial, so she is calling Julien in France to check the first results.

1. How is the trial going?
A It is on track.
B It is behind schedule.
C It is finished.
2. Why is the launch behind schedule?
A Because the customer does not like the adhesive.
B Because the supplier is changing the packaging.
C Because Anna is on vacation.
3. Which sentence is correct?
A “Anna working on a new plan.”
B “Anna is working on a new plan.”
C “Anna is work on a new plan.”

Stage 1.4: Grammar Tip -- Present Continuous -- Things in Progress

GRAMMAR

Use am, is or are + verb-ing for things that are happening now or this week. For things that happen every week, use the present simple.

JobFormExample
Iam + verb-ingI am working on the label.
he / she / itis + verb-ingThe customer is running a trial.
you / we / theyare + verb-ingWe are testing the adhesive.
Negativeam not / isn’t / aren’t + verb-ingWe aren’t waiting for the supplier.
QuestionAm / Is / Are + subject + verb-ing?Are you working on the launch?
The trapevery day, every week = present simpleNot We are sending the report every Friday. Say We send the report every Friday.

Never: We testing the adhesive · The customer is run a trial · They is working · We are sending the report every Friday
