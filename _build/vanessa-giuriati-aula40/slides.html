Chapter 3

Used to It?

Grammar Discovery

Normal Now, or Still New?

"At first, I wasn't used to speaking English in meetings."

"Now I'm getting used to it, gradually."

"My colleague is used to working with people from other countries."

"Don't worry. You'll get used to the accent."

FormUseExample
be used to + -ing / nounIt is normal for you, not strangeShe's used to working late.
not be used to + -ing / nounIt is still new and strangeI'm not used to the cold.
get used to + -ing / nounThe process: it becomes normal, step by stepI'm getting used to my new job.
will get used toEncouragement: it will become normalYou'll get used to it.
⚠ CarefulAfter be used to and get used to, use the -ing form: 'I'm used to speaking', not 'I'm used to speak'. Used to + verb, with no be, is a different thing: a past habit ('I used to live in Rio').
