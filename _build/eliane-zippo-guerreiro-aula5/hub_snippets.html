Etapa 1.3: Grammar in Context

GRAMMAR

Leia o texto em voz alta, devagar, e depois responda as perguntas.

Eliane and her husband are at a restaurant in Miami. "A table for two, please." The waiter says: "Here is the menu."

"I’d like an orange juice, please. My husband’d like a beer."

"And to eat?" "I’d like the chicken with a salad." "And dessert?" "No, thank you. That is all."

1. O que a Eliane pede para beber? (What is her drink?)
A Uma cerveja, igual ao marido dela. (A beer, like her husband.)
B Um suco de laranja. (An orange juice.)
C Um café cubano com açúcar. (A Cuban coffee.)
2. O que ela pede para comer? (What is her food?)
A Frango com salada. (Chicken with a salad.)
B Peixe com arroz, o prato especial da casa. (Fish with rice.)
C Só a sobremesa. (Only dessert.)
3. Ela quer sobremesa? (Does she want dessert?)
A Sim, a torta de limão e um café. (Yes, pie and coffee.)
B Sim, duas sobremesas para o casal. (Yes, two desserts.)
C Não, obrigada. (No, thank you.)

Etapa 1.4: Grammar Tip -- I'd like + a / an

GRAMMAR

I’d like = eu gostaria. É o jeito educado de pedir. / I’d like is the polite way to ask for something.

Uso / UseEstrutura / PatternExemplo / Example
Pedir / To askI’d like = I would likeI’d like the menu, please. (Eu gostaria do cardápio, por favor.)
Antes de consoante / Before a consonantaI’d like a salad. (Eu gostaria de uma salada.)
Antes de som de vogal / Before a vowel soundanI’d like an orange juice. (Eu gostaria de um suco de laranja.)
Para outra pessoa / For another personHe’d like / She’d likeHe’d like a beer. (Ele gostaria de uma cerveja.)
Ideia-chave / Key ideaCuidado: "I like" é "eu gosto"; "I’d like" é "eu gostaria". No restaurante, sempre I’d like. / I like = gosto. I’d like = gostaria.

Quiz

O garçom pergunta: "How many people?" Vocês são dois. Você diz:
A "Two people, I like a table near the window."
B "A table for two, please."
C "I am two, thank you very much."
Você quer um suco de laranja. Você diz:
A "I'd like an orange juice."

O garçom pergunta: "Dessert?" Você não quer. Você diz:

B "I no like dessert."
C "No, thank you. That is all."
