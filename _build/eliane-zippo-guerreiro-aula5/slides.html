Chapter 3: The Code

Two Magic Words

I’d like + a / an

Grammar Discovery

What Do These Four Sentences Have in Common?

"I’d like a table for two, please."

"I’d like an orange juice."

"I’d like a salad."

"I’d like an iced tea."

Look at the blue words. When is it a, and when is it an? Look at the next word: orange, iced... salad, table.

JobFormExample
To ask (polite)I’d like = I would likeI’d like the menu, please.
Before a consonant sound (t, s, b...)aI’d like a salad.
Before a vowel sound (a, e, i, o, u)anI’d like an orange juice.
For another personHe’d like / She’d likeMy husband’d like a beer.

In one line: I’d like is polite. a salad, a table; an orange, an iced tea.
