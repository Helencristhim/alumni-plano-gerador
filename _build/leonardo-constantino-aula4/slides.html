Grammar Discovery

Read and Notice

"If the reform is approved, our clients will need to restructure their tax exposure."

"If we file before the deadline, the client will avoid the penalty."

"If I were advising a foreign bank right now, I would recommend a full compliance review."

"If the regulation changed, the impact would be significant."

Two sentences describe a future the client can plan for. Two describe a future nobody expects. What changes in the verbs?

FormUseExample
First conditional
If + present simple, will + base verb		A real, likely future. The client can plan around it.If the rollout starts in January, the rate will fall by two points.
Second conditional
If + past simple, would + base verb		A hypothesis: unlikely, or simply imagined for analysis.If the incidence moved to the customer, we would rebuild the pricing.
Never "will" after "if"The condition itself carries no will: If the reform passes, not "if the reform will pass".
were, not wasIn the second conditional, formal English uses were for every person: If I were you. If it were my money.
OrderBoth halves can swap. With if first, use a comma: If the rollout slips, the offset arrives too late. / The offset arrives too late if the rollout slips.
unlessunless = if not. Unless the board approves it, we will not file this quarter.

The test is simple: ask yourself is this on the table? If yes, first conditional. If it is a hypothesis, second.

Common Mistake

Right vs Wrong

"If the reform will pass, the rate will go up."
"If the reform passes, the rate will go up."
"If I would be the CFO, I would wait."
"If I were the CFO, I would wait."
"If the rate changed, the impact will be significant."
"If the rate changed, the impact would be significant."

The two halves must agree: present + will for a real future, past + would for a hypothesis. The condition itself never takes will or would.
