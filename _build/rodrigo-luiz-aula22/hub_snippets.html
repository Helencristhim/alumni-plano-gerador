Etapa 1.3: Grammar in Context

Grammar

Leia o texto em voz alta e repare em should e shouldn’t: é ordem ou conselho? Depois responda as perguntas.

Last month the demand for a strawberry flavor was very high, but the forecast was low. A big customer called: the order was urgent. Rodrigo asked the global team for advice. Claire said: "You should call the customer today. You shouldn't promise a date now. The priority is the customer." Now the team should update the forecast every week.

1. O que a Claire disse para fazer hoje? (What should he do?)
A Trabalhar no sábado com o time inteiro.
B Comprar mais morango.
C Ligar para o cliente.
2. O que ele NÃO deve fazer agora? (Shouldn't)
A Prometer uma data.
B Ligar para o cliente hoje.
C Falar com o time global sobre o pedido.
3. Qual é a prioridade? (Priority?)
A O preço da matéria-prima importada.
B O cliente.
C O fórum de KPI.

Etapa 1.4: Grammar Tip -- should e shouldn't: dar e pedir conselho

Grammar

should = deveria / é bom: um conselho, não uma ordem. shouldn’t = não deveria. Depois dos dois, o verbo vem na forma base: sem to e sem -s. / Should + base verb.

Uso / UseEstrutura / PatternExemplo / Example
Conselho / Adviceshould + verboYou should call the customer. (Você deveria ligar para o cliente.)
Negativa / Negativeshouldn't + verboYou shouldn't promise a date. (Você não deveria prometer uma data.)
Pergunta / QuestionShould + sujeito + verbo?Should we work on Saturday? (Devemos trabalhar no sábado?)
Pedir conselho / AskWhat should we do?What should we do? (O que devemos fazer?)
Cuidado / Careful—Sem to e sem -s: "He should to call" e "He shoulds" estão errados. O certo é "He should call". / No to, no -s.

Etapa 3: Pronúncia

Speaking

Ouça, grave você falando e ouça de novo. Dois pontos: o L de should não soa (XUD), e shouldn’t termina num T quase mudo.
