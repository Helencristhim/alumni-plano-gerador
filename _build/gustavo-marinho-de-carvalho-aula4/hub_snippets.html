If I Could Change One Thing -- Opinions in the Hypothetical

An opinion with a trade-off named out loud is worth ten without one. Key words: a trade-off, to be worth it, an impact, to afford, in the long run, to make sense, a downside, to weigh up. Structure: second conditional.

Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example. Tap Listen to hear it.

A trade-off -- a situation where you gain one thing but lose another
"There is a trade-off: faster buses, and a cost for people just outside the zone."
To be worth it -- to give you enough in return for what it costs
"It is expensive and slow, and I still think it is worth it."
An impact -- the effect that something has on a situation or on people
"The impact on the buses was immediate. The impact on the shops took years to measure."
To afford -- to have enough money, time or room for something
"We could afford the fine. We could not afford the delay."
In the long run -- over a long period, not immediately
"In the long run it pays for itself. In the first year it does not."
To make sense -- to be a reasonable and logical thing to do
"It would make sense to try it in one district before the whole city."
A downside -- the disadvantage of something that is otherwise good
"The downside is that it costs the same for everybody, and not everybody has a choice."
To weigh up -- to compare two things carefully before you decide
"Before you answer, weigh up what you gain against what the other side loses."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text, then answer the questions.

Last lesson you learned the shape for a condition that might really happen this week: if you send it today, I will have it ready. Present in one half, will in the other. Today the sentence moves one step away from reality, and English marks that move by putting the condition in the past.

If we moved to a four-day week, we would need far fewer meetings. Nobody is moving. If it were my decision, I would start with the buses. It is not my decision. The past tense here has nothing to do with the past: it is a distance marker, and the distance is exactly what makes the sentence usable in an argument. It puts the idea one step away from the person saying it, so the other side can disagree with the idea without disagreeing with you.

Two traps, and a Brazilian speaker walks into both. The first is would in the wrong half: in Portuguese the conditional ending appears twice, so the hand wants to write if I would have more time. English allows it in exactly one half. Say if I had more time, I would read it properly. The second is if I was. In careful English it is if I were — for every person, including I and it. And one bonus: the most useful sentence of the lesson has no if at all. It would make sense to start smaller is an opinion, a suggestion and an invitation to answer, in seven words.

1. What does the past tense do in “if we moved to a four-day week”?
A It says the move happened last year.
B It marks distance from reality, not time.
C It makes the sentence more formal, with no change in meaning.
2. According to the text, why is the hypothetical useful in an argument?
A It puts the idea one step away from the person, so the other side can disagree with the idea and not with you.
B It hides what you really think, which avoids conflict.
C It is the only polite form in British English.
3. Why does the text say a Brazilian speaker writes “if I would have more time”?
A Because the verb have is irregular.
B Because in Portuguese the conditional ending appears in both halves.
C Because English allows it in speech but not in writing.

Stage 1.4: Grammar Tip -- Second Conditional

GRAMMAR

The past tense here does not move the sentence back in time. It moves it one step away from reality.

JobFormExample
Real and likely (last lesson)if + present simple, willIf you send it today, I will have it ready.
Imagined, unreal or unlikelyif + past simple, would + base verbIf we moved the office, we would lose half the team.
Putting yourself in their placeif I were you, I would...If I were you, I would try one district first.
Softening an opinion, with no ifit would + verb / I would sayIt would make sense to start smaller.
The past here is not the pastit marks distance, not timeIf I had more time, I would read it properly. (I do not.)
The trapnever would in the if halfNot If I would have time. Say If I had time.
The second trapwere for every person, in careful EnglishNot If I was you. Say If I were you.

Never: If I would have more time · If I was you · If my city will adopt this, traffic will fall · It would makes sense

Stage 2: Put the Argument in Order

Order

You are defending an idea to somebody who disagrees. Put the six lines in a logical order.

?"We both want the same thing here, so let me start from that."
?"If it were my decision, I would start with the buses."
?"The impact on the first year would be small, I accept that."
?"And there is a downside: it costs the same for people with no alternative."
?"Even so, in the long run I think it would be worth it."
?"What would change your mind here?"

Stage 4: Situational Quiz

Quiz

Choose the answer a real speaker would give.

The client asks what you would do if the decision were yours. You answer:
A If it would be my decision, I would start with the buses.
B If it were my decision, I would start with the buses.
C If it is my decision, I will start with the buses.
You are defending an idea you believe in. The strongest move is:
A Say what you would do, name the downside yourself, and say why it would still be worth it.
B List only the advantages, so that the idea sounds stronger.
C Say that anybody who disagrees has not read the numbers.
The brief really might arrive this afternoon. The correct shape is:
A If the brief arrived this afternoon, I would start tomorrow.
B If the brief arrives this afternoon, I will start tomorrow.
C If the brief would arrive this afternoon, I start tomorrow.
She says she is not convinced. The most useful thing you can say is:
A Why do you think that? The numbers are very clear.
B That is fair. What would change your mind here?
C Are you sure? Most people agree with this now.

Stage 5: Free Production

Reflection

Think, then record your answer. There is no wrong answer here.

Ninety seconds, no notes. One thing you would change about the city you live in. Say what you would do, who would pay for it, what the downside would be, and why you would still say it is worth it. Finish with the question you would ask somebody who disagreed.
