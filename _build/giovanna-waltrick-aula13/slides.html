Chapter 3: The Code

If This, Then That

Not one day. Every time.

Discover the Rule

What Do the Orange Verbs Have in Common?

If a brand makes too much, it loses money.
If the manager approves the sample, the factory starts.
When the supplier delivers late, the whole process stops.
If you don't check the invoice, you pay the wrong amount.
Click to reveal the rule
All the orange verbs are in the present simple, on BOTH sides of the sentence: If / When + present simple, present simple. We use it for things that are always true: facts, rules and processes, every time, not one day. Here if and when mean almost the same. Never use will after if here: if the manager will approve is wrong; it is if the manager approves. Comma when if starts the sentence; no comma when it is in the middle: The factory starts if the manager approves the sample.

Sold Out Again

R
The jacket I wanted is sold out again. Why don't brands just make more?
G
Because if a brand makes too much, it loses money. Old stock is very expensive.
R
But they know it is popular. Why can't they make more next week?
G
It is not that fast. When the supplier is in another country, the fabric takes two months.
R
Two months? I thought there was a big machine somewhere. What happens first?
G
First, they make one sample. If the manager approves it, the factory starts. If not, the process starts again.
R
You sound like somebody who works there. So what do I do now?
G
I study it, that's why. If you join the waiting list, you get an email when it is back.
