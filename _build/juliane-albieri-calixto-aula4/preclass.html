Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example. Tap Listen to hear it.

A prompt -- the instruction or question you write for an AI tool
"A good prompt gives context, a task and a format."
A token -- a small piece of text that an AI model reads and counts
"The same prompt in English often uses fewer tokens."
An output -- the result that a tool or a system gives you
"The first output was too long."
To generate -- to create or produce something, often automatically
"The tool can generate ten versions of a screen in a minute."
Accurate -- correct and exact, with no mistakes
"The text was fast, but it was not accurate."
To refine -- to improve something with small changes
"I always refine the prompt two or three times."
A draft -- a first version of a text or a design, not final
"AI is great for a first draft."
To rely on -- to trust something or someone and depend on it
"I would not rely on the first answer."
A workflow -- the sequence of steps a team follows to do a job
"AI has changed the workflow of my team."
To automate -- to make a task happen with a machine, without a person doing it
"We could automate the boring parts of the job."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text, then answer the questions.

Juliane’s team uses AI tools every day. The tools generate a first draft of a screen in seconds. But the output is not always accurate, so the team never relies on the first answer.

A new designer asks: “If AI designed every screen, what would we do?” Juliane answers: “We would spend more time on the problem. If I were you, I would learn to write good prompts.”

She also says that prompts in English often use fewer tokens. “If we wrote every prompt in English, our workflow would be faster.”

1. Why does the team not rely on the first answer?
A Because the output is not always accurate.
B Because the tools are too slow.
C Because the tools only work in Portuguese.
2. Is it true that AI designs every screen in Juliane’s team?
A Yes, that is why the sentence uses the past.
B No: “if AI designed” is an imaginary situation.
C Yes, but only last year.
3. Which sentence is correct?
A “If I would be you, I would learn to write prompts.”
B “If I were you, I would learn to write prompts.”
C “If I am you, I would learn to write prompts.”

Stage 1.4: Grammar Tip -- Second Conditional -- Imaginary Situations

GRAMMAR

For a situation that is not real, use if + past simple. For the imaginary result, use would + verb. To give advice: If I were you, I would...

JobFormExample
The imaginary situationif + past simpleIf I had more time...
The imaginary resultwould + verb...I would test more prompts.
Be in the if-partwere for everybodyIf I were you... If it were easy...
AdviceIf I were you, I would...If I were you, I would refine the prompt.
QuestionsWhat would you do if...?What would you do if you won?
The trapno would in the if-partNot if I would have time. Say if I had time.

Never: If I would have time · If AI design everything, we would · If I had time, I will · What you would do?
