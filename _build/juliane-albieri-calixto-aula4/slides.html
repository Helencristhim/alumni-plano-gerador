Chapter 4: The Code

What Would You Do?

Imaginary situations and advice

Grammar Discovery

Four Sentences That Are Not Real

"If AI designed every screen, we would focus on the problem."

"If I had more time, I would test more prompts."

"What would you do if a tool did half of your work?"

"If I were you, I wouldn’t rely on the first output."

Is AI designing every screen today? No. Do you have more time? No. These sentences are imaginary. Look at the blue verbs in the if-part: they are in the past (designed, had, did, were), but they talk about now. The past is the sign of imagination. The red part takes would + the simple verb.

JobFormExample
The imaginary situationif + past simpleIf I had more time...
The imaginary resultwould + verb...I would test more prompts.
Be in the if-partwere for everybodyIf I were you... If it were easy...
AdviceIf I were you, I would...If I were you, I would refine the prompt.
QuestionsWhat would you do if...?What would you do if you won?
The trapno would in the if-partNot if I would have time. Say if I had time.

In one line: if + past for the imaginary situation, would + verb for the imaginary result; never would after if.

Chapter 5: Two Voices

A Prompt, and Two Voices

One prompt card, two recordings

Real Document

A Prompt With Context

PROMPT CARD
Five parts of a good prompt · Example
RoleYou are an editor for an international design award.
ContextThe project is a credit card feature for Brazilian bank customers.
TaskWrite a short project description for a foreign jury.
FormatThree paragraphs: problem, solution, result. Simple English.
LimitsMaximum 150 words. No technical words from banking.
CheckIs it accurate? Would a foreign reader understand it?
Most weak outputs come from weak context. If the prompt had no context line, the tool would write a generic text about credit cards. The two lines in color are the ones most people forget.
1. What would happen if the prompt had no context line?
The tool would write a generic text.
2. Which line protects a foreign reader?
The limits line: no technical words from banking.
3. Why should you not rely on the first output?
Because it can be fast but not accurate; you need to check and refine it.
