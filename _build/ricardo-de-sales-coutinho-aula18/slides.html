Chapter 3: Can I Have...?

Ask Politely

and a, some, any

Grammar Discovery

Listen and Notice

"I'd like a sandwich, please."

"Can I have some water?"

"I'd like some rice."

"Do you have any fish?"

WordsUse it forExample
I'd like ...to ask, politely (= I want)I'd like the chicken.
Can I have ...?to ask, politelyCan I have the check?
a / anONE thing you can counta sandwich · a coffee
somea quantity, no numbersome rice · some water
anyin questions and with notDo you have any fish?

I'd like = I would like. Rice and water: no number, so some.

Count It or Not?

A or Some?

"I'd like a sandwich."

one sandwich — you can count it

"I'd like two sandwiches."

two, three... — you can count it

"I'd like some rice."

rice — you cannot count it

"We don't have any fish today."

any, with not
