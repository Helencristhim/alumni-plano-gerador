Etapa 1.3: Grammar in Context

GRAMMAR

Leia o e-mail em voz alta, devagar, e depois responda as perguntas. Ele tem um pouco de cada aula.

Subject: Ticket 619 -- VPN not working

Hi Linda, I am the IT analyst for this ticket. Our users can't log in to the VPN, and the connection doesn't work from home. The screenshot is in the attachment. Can you help us, please?

Update: the VPN is working now. The problem is solved, so the ticket can be closed. Don't change anything, please. Best regards, Diogo.

1. Onde está o print do erro? (Where is the screenshot?)
A No assunto do e-mail, junto com o número do chamado. (In the subject.)
B Com a Linda. (With Linda.)
C No anexo. (In the attachment.)
2. Qual frase está no presente contínuo (aula 5)?
A "The VPN is working now."
B "The connection doesn't work from home in the morning."
C "Can you help us?"
3. Como o Diogo termina o e-mail? (How does he end the email?)
A "Bye bye, see you, Diogo." (Tchau.)
B "Best regards, Diogo." (Atenciosamente.)
C "Subject: Diogo." (Assunto.)

Etapa 1.4: Grammar Tip -- Revisão das 5 ferramentas

GRAMMAR

Nenhuma regra nova: as cinco estruturas das aulas 1 a 5, num lugar só. / No new rule: the five structures from lessons 1 to 5.

Aula / LessonEstrutura / PatternExemplo / Example
1 -- quem sou / who I amam / is / areI am the IT analyst. (Eu sou o analista de TI.)
2 -- o problema / the problemdon’t / doesn’t + verboIt doesn’t work. (Não funciona.)
3 -- o pedido / the requestcan / can’t + verboCan you help us? (Você pode nos ajudar?)
4 -- os passos / the stepsverbo / don’t + verboDon’t change anything. (Não mude nada.)
5 -- agora / nowam / is / are + verbo-ingThe VPN is working now. (A VPN está funcionando agora.)
Ideia-chave / Key ideaUm e-mail de suporte usa as cinco: quem você é, o que não funciona, o pedido, os passos e o que está acontecendo. / A support email uses all five.

Etapa 4: Quiz Situacional

Quiz

Escolha a melhor resposta para cada situação. Errou? Tente de novo.

Você vai escrever o assunto do e-mail para o fornecedor. O melhor é:
A "Subject: Ticket 619 -- VPN not working"
B "Subject: Hello, how are you, I have a question for you."
C "Subject: Problem."
O problema acabou. Você avisa o fornecedor:
A "The problem solved. You can to close the ticket now, please."
B "The problem is solved. You can close the ticket."
C "The problem no is. Close."
Você quer dizer que o print está no anexo:
A "The screenshot are in the attachment of this email for you."
B "The screenshot in the attachment."
C "The screenshot is in the attachment."
