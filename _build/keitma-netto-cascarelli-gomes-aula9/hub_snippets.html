Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example. Tap Listen to hear it.

To chase -- to ask again for something that has not arrived yet
"I have been chasing that file since Monday."
A bottleneck -- the one step where everything else has to wait
"The bottleneck is the approval, not the preparation."
To push back -- to move a date to a later one, and agree it with somebody
"Can we push the review back to Wednesday morning?"
To prioritize -- to decide what gets done first when everything is late
"If we prioritize the two big accounts, the rest can wait a day."
A dependency -- something you cannot finish until somebody else finishes theirs
"The tax file is a dependency, and it is the only one left."
At short notice -- with almost no time to prepare
"They asked for the whole pack at short notice, on a Friday."
To keep somebody posted -- to keep somebody informed while the situation is still moving
"I will keep you posted through the afternoon."
A workaround -- a different way of getting there when the normal way is blocked
"There is a workaround, but it has to be documented."
To free up -- to make time or people available for something else
"If the BPO takes the postings, that frees up half a day."
To commit to a date -- to give a date that the other person can rely on
"I can commit to Wednesday morning, not to Tuesday."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text, then answer the questions.

Two messages about the same late file. You have not sent me the file yet. And: if you send me the file today, I can still close the account this month. Both are true and both are polite. The first one is about the past and about the person receiving it, and it usually gets an apology. The second is about the future and about the work, and it usually gets the file.

The shape that does the work is the first conditional, and it has one detail that catches almost every learner. Both halves are about the future, but only one of them is allowed to say so. The if half takes the present: if you send it today, never if you will send it. The other half takes will or can: I can still close it. The same applies to the negative version, and to unless, which is simply if not compressed into one word: unless it arrives by Tuesday, I will have to push the review back.

The other half of this lesson is what turns an instruction into a request. Could you takes the bare verb: could you send me the reconciliation? Would you mind takes the -ing form, which is the detail people get wrong: would you mind sending it before the call? — never to send. And whichever one you use, attach the reason with so that. The reason is not decoration and it is not politeness: it is the part that competes with everything else on the other person's list, and it is the only part of your message that they are actually weighing.

1. What does the text say the first message usually gets, and what does the second one get?
A The first gets an apology; the second gets the file.
B The first gets the file; the second gets an apology.
C Both get the same answer, because both are polite.
2. Which half of a first conditional carries the future word?
A The if half, because that is the part that has not happened.
B The other half — the if half takes the present.
C Both halves, for emphasis.
3. According to the text, why does the reason matter?
A Because it makes the message sound more polite.
B Because it is what competes with everything else on the other person's list.
C Because English grammar requires a reason after could you.

Stage 1.4: Grammar Tip -- If, Unless, and the Polite Request

GRAMMAR

Present in the if half. Future in the other. Reason always attached.

ShapeWhat it doesExample
if + present, will / cana real future conditionIf you send it today, I can still close it.
if + negative presentthe consequence of nothing arrivingIf it does not arrive by Tuesday, I will push it back.
unlessif not, in one wordUnless it arrives by Tuesday, I will push it back.
could you + bare verba request, not an instructionCould you send me the reconciliation?
would you mind + -ingsofter still, and note the formWould you mind sending it before the call?
so thatthe reason that makes it easy to say yes... so that I can check one number before the call.
the trapno will after if; no to after would you mindNot if you will send. Not would you mind to send.
the one that travels with ityou send something to a person, on a day, by a deadlineI will send it to you on Wednesday, by midday.

Never: if you will send me the file · would you mind to send it · I will send it for you in Wednesday · at this week

Stage 4: Situational Quiz

Quiz

Choose the answer a real speaker would give.

You are chasing a late file. The message that gets an answer is:
A You have not sent me the file yet.
B If you send me the file today, I can still close the account this month.
C If you will send me the file today, I can close the account.
You want to soften a request as much as possible. You say:
A Would you mind to send it before the call?
B Would you mind sending it before the call, so that I can check one number?
C Send it before the call, please, I need to check a number.
It is day two and you already know you need one more day. You say:
A Could you give me until Wednesday morning, and I will send you the completed reconciliation?
B I am so sorry, I am really sorry, I think maybe I will not finish on time.
C It will be late, the tax team did not send anything.
Your manager asks what date you can promise. You say:
A I hope Tuesday, but it depends of the tax team.
B I can commit to Wednesday morning, not to Tuesday. I will keep you posted.
C Maybe Tuesday, maybe Wednesday, I am not sure yet.

Stage 5: Free Production

Reflection

Think, then record your answer. There is no wrong answer here.

Ninety seconds, no notes. Take a real deadline from your own last close that was at risk. Say what the dependency was, what you asked for and from whom, what would have happened if it had not arrived, and what you committed to. Finish with one question back.

Twelve minutes on what people really mean when they say there is no time, and on the sentence that changes a negotiation about a deadline: not I do not have time, but it is not a priority. Direct, slow and very quotable.

Tip: after watching, take one thing you are late on and say it out loud in her words. Then say it again as a first conditional, with what happens if it moves.
