Aula 21 -- Pre-class

Reporting a Problem -- because e so

Quando algo atrasa, o time global quer três coisas: o que aconteceu, por quê e o que acontece agora. Aqui você aprende os dois conectores que fazem isso numa frase: because (a causa) e so (o resultado).

Etapa 1.3: Grammar in Context

Grammar

Leia o texto em voz alta e repare em because e so: qual traz a causa e qual traz o resultado? Depois responda as perguntas.

This month there is a shortage of vanilla, so the price of the raw material is higher. The vanilla for the Paris order is late because it is still at the port of Santos. Customs is checking every container, so the process is slow. Rodrigo has a solution: a second supplier in Brazil. The supplier is ready, so the next order is going to be on time.

1. Por que a baunilha está atrasada? (Why?)
A Porque o fornecedor de Paris fechou a fábrica.
B Porque ainda está no porto de Santos.
C Porque o caminhão quebrou.
2. Qual é o resultado da falta de baunilha? (So...?)
A O preço está mais alto.
B O pedido de Paris foi cancelado pelo cliente.
C A alfândega fechou o porto.
3. Qual é a solução do Rodrigo? (Solution?)
A Esperar a alfândega por mais um mês.
B Cancelar o pedido de Paris.
C Um segundo fornecedor.

Etapa 1.4: Grammar Tip -- because (a causa) e so (o resultado)

Grammar

because = porque: responde por quê? e vem antes da causa. so = então, por isso: vem antes do resultado, quase sempre depois de vírgula. / Because gives the reason; so gives the result.

Uso / UseEstrutura / PatternExemplo / Example
Causa / Reasonresultado + because + causaIt is late because customs is slow. (Está atrasado porque a alfândega está lenta.)
Resultado / Resultcausa + , so + resultadoCustoms is slow, so it is late. (A alfândega está lenta, então está atrasado.)
Pergunta / QuestionWhy...? — Because...Why is it late? — Because the truck had a problem. (Por que está atrasado? — Porque o caminhão teve um problema.)
Falta / ShortageThere is a shortage of..., so...There is a shortage of vanilla, so the price is higher. (Há falta de baunilha, por isso o preço subiu.)
Cuidado / Careful—Use UM conector só: "Because it is late, so..." está errado. E depois de because vem uma frase completa: "because customs is slow", não "because slow". / One connector, not two.

Etapa 3: Pronúncia

Speaking

Ouça, grave você falando e ouça de novo. Dois pontos: because é bi-CÓZ, a força no fim; e antes do so há uma pequena pausa, a vírgula falada.

The order is late because customs is slow.
O pedido está atrasado porque a alfândega está lenta.
There is a shortage, so the price is higher.
Há falta do produto, então o preço está mais alto.
We have a problem with the raw material.
Temos um problema com a matéria-prima.
We have a second supplier, so it is not a problem.
Temos um segundo fornecedor, então não é problema.
