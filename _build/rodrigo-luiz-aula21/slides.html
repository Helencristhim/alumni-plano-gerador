Chapter 3: The Pattern

Why? And Then?

because · so

Grammar Discovery

Listen and Notice

The order is late because the vanilla is at the port.
Customs is slow, so the vanilla is late.
The price is higher because there is a shortage.
We have a second supplier, so the next order is OK.

Two orange words. Which one gives the REASON, and which one gives the RESULT?

UseFormExample
Reason (why?)result + because + reasonThe order is late because customs is slow.
Result (and then?)reason + , so + resultCustoms is slow, so the order is late.
QuestionWhy...? — Because...Why is it late? — Because the truck had a problem.
Same storybecause looks back, so looks forwardThere is a shortage, so the price is higher.
CarefulONE connector, not two: "Because it is late, so..." is wrong. And because needs a full sentence: because customs is slow, never "because slow".

Chapter 4: The Delay

The Vanilla Is Late

a call from Paris

Dialogue

The Order for Paris

C
Rodrigo, the order for Paris is late. What happened?
R
We have a problem with the raw material. The vanilla is still at the port.
C
Why is it still there?
R
Because customs is very slow this month. They are checking every container.
C
OK. So when is the order ready?
R
The vanilla arrives on Thursday, so the order is ready on Monday.
C
Is there a shortage in Brazil too?
R
Yes, there is a shortage of vanilla, so the price is higher.
C
Do you have a solution?
R
Yes. We have a second supplier, so the next order is not going to be late.
