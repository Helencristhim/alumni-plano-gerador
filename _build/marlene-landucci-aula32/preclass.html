Stage 1.4: Grammar Tip -- Sense verbs (it tastes / looks / smells + adjective)

GRAMMAR

Para descrever comida com os sentidos, use tastes (gosto), looks (aparência) e smells (cheiro) + ADJETIVO. Com it, o verbo ganha -s. Pergunta: What does it taste like? / Use taste, look and smell + an adjective.

RuleExample (EN)Tradução (PT)
GostoIt tastes sweet.Tem gosto doce. / É doce.
AparênciaIt looks delicious.Parece delicioso.
CheiroIt smells good.Tem um cheiro bom.
PerguntaWhat does it taste like?Que gosto tem?
NegativoIt doesn't taste sweet.Não é doce.
Um pouco / muitoIt tastes a little sour.É um pouco azedo.

Key point / Ponto-chave: depois de tastes/looks/smells vem ADJETIVO: It smells good (nunca "smells well"). Não esqueça o -s: it tastes. Na pergunta, o like fica no fim: What does it taste like? Em italiano: sa di = tastes like.
