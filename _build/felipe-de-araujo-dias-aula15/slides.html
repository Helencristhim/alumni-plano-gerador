Chapter 3: Not Real, Not Yet

If I Had, I Would

The second conditional

Grammar Discovery

Listen and Notice

"If I had the budget, I would change the process."

"If store managers approved small repairs, they would save a week."

"If I were you, I would talk to finance first."

"We could start with a pilot if the CEO agreed."

FormUse it forExample
If + past, would + verbAn imaginary situation now, and its result.If I had the budget, I would change it.
would + verb if + pastThe same idea, result first. No comma.Repairs would be faster if we cut approvals.
If I were you, I would...Advice. Were for every person.If I were you, I would wait.
could / might + verbA possible result, less certain than would.We could start with a pilot.
First vs secondReal possibility: if + present, will. Imagined: if + past, would.If it arrives, we will... / If I were CEO, I would...

Never would after if. The if half is in the past, but it is not about the past: it is about a situation that is not real.

Grammar Practice

3. Store managers ______ (solve) problems in a day if they ______ (have) the authority.
"Store managers would solve problems in a day if they had the authority."

"If finance didn't agree, we could try it in ten stores."

Chapter 4: The Conversation

What Would You Change?

Testing the idea before the offsite

Dialogue

What Would You Change?

I
So, Felipe. If you could change one thing in the company, what would it be?
F
The approvals for small repairs. Today every repair needs three.
I
Even a broken door?
F
Even a broken door. The store manager waits nine days, and fills in the same paperwork three times.
I
And what would you do instead?
F
I would empower the store managers. If they approved repairs below two thousand reais, they would solve most problems in a day.
I
Would it cost anything?
F
Nothing. It would actually save money, and a lot of time.
I
What would finance say?
F
They would worry about control. That is the main drawback, and I understand it.
I
So how would you get their buy-in?
F
With a pilot. If we started in twenty stores, we would have real numbers in three months.
