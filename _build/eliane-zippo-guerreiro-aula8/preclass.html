Etapa 1.3: Grammar in Context

GRAMMAR

Leia o texto em voz alta, devagar, e depois responda as perguntas.

It is Black Friday in Miami. The sale is big. Eliane says: "This bag is beautiful. And those shoes over there?"

"These shoes are forty dollars, and that bag is sixty." Those jeans are on sale too.

"I’d like this perfume. It is a gift." Her husband says: "And these sunglasses? They are for me!"

1. Quanto custam os sapatos? (How much are the shoes?)
A Sessenta dólares, com a bolsa junto. (Sixty, with the bag.)
B Quarenta dólares. (Forty dollars.)
C Estão de graça na Black Friday. (They are free.)
2. O perfume é para quem? (Who is the perfume for?)
A É um presente. (It is a gift.)
B Para o marido dela, junto com os óculos de sol. (For her husband.)
C Para a vendedora da loja. (For the sales assistant.)
3. Os óculos de sol são para quem? (Who are the sunglasses for?)
A Para a Eliane, para a praia de Miami Beach. (For Eliane, for the beach.)
B Para uma amiga em São Paulo. (For a friend.)
C Para o marido dela. (For her husband.)

Etapa 1.4: Grammar Tip -- This, that, these, those

GRAMMAR

Perto ou longe? Um ou vários? / Near or far? One or many?

Uso / UseEstrutura / PatternExemplo / Example
Perto + um / Near + onethis (este, esta)This bag is beautiful. (Esta bolsa é linda.)
Longe + um / Far + onethat (aquele, aquela)That bag is sixty dollars. (Aquela bolsa custa sessenta.)
Perto + vários / Near + manythese (estes, estas)These shoes are forty dollars. (Estes sapatos custam quarenta.)
Longe + vários / Far + manythose (aqueles, aquelas)Those sunglasses are expensive. (Aqueles óculos são caros.)
Ideia-chave / Key ideaUm: this / that + is. Vários: these / those + are. E atenção: em inglês, shoes, jeans e sunglasses são sempre plural: these jeans, those sunglasses. / One: is. Many: are.
