Lesson 03 -- Pre-class

If We Get This Right

Selling a plan that does not exist yet. Key words: onboarding, stakeholder, root cause, buy-in, to pilot, to scale, initiative, succession plan. Structure: first conditional, with unless, as long as, provided that and in case.

Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example out loud. These are the words a proposal is written with.

Onboarding -- the first weeks of a new employee inside the company
"Half of the people who leave in the first year leave because of onboarding."
Stakeholder -- anybody whose work is affected by a decision you make
"Finance is the stakeholder I have to convince first."
Root cause -- the real reason behind a problem, not the visible symptom
"Overtime is the symptom. The root cause is how we plan the shifts."
Buy-in -- the agreement of the people who have to support a decision
"Without buy-in from the site managers, nothing will happen."
To pilot -- to test a program in one small area before you launch it everywhere
"We are going to pilot it in one site, starting in March."
To scale -- to make something work for a much bigger number of people
"If the pilot works, we will scale it to the whole region."
Initiative -- a program you start in order to change something
"The initiative has one owner and one number to move."
Succession plan -- the list of people ready to take a key role if it becomes empty
"If we lose that manager tomorrow, the succession plan is one name long."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text and answer the questions.

The proposal is one page long. It says that the root cause of early attrition is the first month, not the salary. If we pilot a structured onboarding program in one site, early attrition will fall by at least five points in ninety days. Unless it falls by five points, there will be no second pilot. As long as the site managers release the time, the program costs almost nothing. Finance is the first stakeholder: if the director reads the page before the meeting, nobody in the room will argue with the numbers. And the last line is the one that gets it approved: if it does not work, we stop, and the owner brings the reason.

Stage 1.4: Grammar Tip -- First Conditional

GRAMMAR

The first conditional talks about a real, likely future. Two halves: if + present simple for the condition, and will + verb for the consequence.

basic formif + present, willIf the pilot works, we will scale it to the region.
unless= if notWe will not get approval unless finance supports it.
as long as / provided that= only on this conditionAs long as the managers release the time, this will work.
in case= as a precaution, beforeI will prepare a second version in case they ask for one.
ordereither half firstWe will stop if it does not work. / If it does not work, we will stop.

The trap: never put will after if. It is "if the pilot works", never "if the pilot will work". And unless already carries the negative, so "unless we do not get buy-in" says the opposite of what you mean.

Stage 4: Situational Quiz

Quiz
You want to say that scaling depends on the pilot working. Which sentence is correct?
A "If the pilot will work, we will scale it."
B "If the pilot works, we will scale it."
C "If the pilot work, we scale it."
Approval depends on finance supporting the proposal. Which sentence says that?
A "We will not get approval unless finance supports it."
B "We will not get approval unless finance does not support it."
C "We will get approval unless finance supports it."
You are preparing a shorter version as a precaution, before anybody asks. What do you say?
A "I will prepare a shorter version if they ask for one, after the meeting."
B "I will prepare a shorter version in case they ask for one."
C "I prepare a shorter version unless they ask for one."
The board asks what happens if the pilot fails. Which answer sounds senior?
A "It will work, I am sure about that."
B "If it does not reduce attrition by five points, we stop in ninety days."
C "I do not want to think about that now."
