Etapa 1.3: Grammar in Context

Grammar

Leia o texto em voz alta e depois responda as perguntas. (Leia devagar -- ninguém está contando o tempo.)

This is my evaluation of the new platform. The first screen is very clear, and the videos are simple and short. For a teacher on the first day, that is really useful. But the report page is difficult: many teachers do not find it, and that is an important problem. The general idea of the tool is very powerful, and the project is really interesting. It is a useful tool for public schools, and with one change it can be an excellent one.

1. Por que escrevemos "a very useful platform" e não "a platform very useful"? (Why here?)
A Porque em inglês o adjetivo vem ANTES do substantivo. (Antes do substantivo.)
B Porque "platform" é feminino. (Por causa do gênero.)
C Porque a frase é longa. (Por ser longa.)
2. Por que "interesting sessions" e não "interestings sessions"? (Why no -s?)
A Porque o adjetivo em inglês NUNCA vai para o plural. (Adjetivo não tem plural.)
B Porque "sessions" já está no plural e basta um. (Já tem um -s.)
C Porque é uma palavra longa. (Por ser longa.)
3. Qual é o problema da plataforma, segundo o texto? (What is the problem?)
A Os vídeos são longos demais. (The videos are too long.)
B A página de relatório é difícil de achar. (The report page is difficult.)
C A primeira tela é confusa. (The first screen is confusing.)

Etapa 1.4: Grammar Tip -- Onde entra o adjetivo, e como reforçá-lo

Grammar

Duas posições, e uma forma só: o adjetivo em inglês nunca muda. / Two positions, one shape -- the adjective never changes.

PosiçãoEstrutura / PatternExemplo / Example
Antes do substantivoadjetivo + substantivoa useful platform (uma plataforma útil)
Depois do verbo to beis / are + adjetivoThe screen is clear. (A tela é clara.)
Para reforçarvery / really + adjetivoIt is very useful. / It is really difficult.
Sem pluralo adjetivo NUNCA ganha -sinteresting sessions — nunca "interestings"
Ideia-chave / Key ideaEm português o adjetivo vem DEPOIS do substantivo e concorda com ele (plataformas úteis). Em inglês ele vem ANTES e nunca muda: useful platforms. / In English: before the noun, and never changes.
