Capítulo 3: El Código

Estoy Hablando

estar + -ando / -iendo

Descubre la Regla

Escucha y Observa

"María está compartiendo la pantalla."

"Yo estoy probando el micrófono."

"Diego está leyendo el informe."

"Estamos esperando a los colegas de México."

¿Estas acciones pasan ahora o todos los días?

EstructuraEjemplo
estar: estoy, estás, está, estamos, estánEstoy trabajando.
verbos -AR → -andohablar → hablando · esperar → esperando
verbos -ER / -IR → -iendocomer → comiendo · compartir → compartiendo
leer → leyendoDiego está leyendo el informe.

Como en portugués: estou falando = estoy hablando. El gerundio no cambia.
