Lesson 07 -- Pre-class

If the Cue Runs Long

In a recorded session a mistake is a delay. Live, a mistake is a decision, and you have four seconds. Key words: to go live, a glitch, to drop out, a backup, a fallback, to patch, to cue somebody, to abort, downtime, redundancy, to troubleshoot, worst case. Structure: the if half always stays in the present, and only the other half can look at the future.

Stage 1.1: Vocabulary Cards

Vocabulary

Listen to each word and read the example. Tap Listen to hear it.

To go live -- to start broadcasting or performing in real time, with no way to stop
"We go live at nine. After that, every mistake is a decision."
A glitch -- a small, sudden technical fault
"It was a glitch, not a failure. It came back on its own after two seconds."
To drop out -- to stop working or disappear suddenly, usually for a short time
"If the backing track drops out, the room goes quiet and somebody has to speak."
A backup -- a copy kept in case the original is lost or fails
"There is a backup on a second machine, already loaded."
A fallback -- the plan you use if the first one fails
"The fallback is the recorded version, and it is two seconds away."
To patch -- to connect or route a signal from one place to another
"I can patch the second machine in about four seconds."
To cue somebody -- to give the signal that tells somebody to start
"If she looks at me, I cue the band. If she does not, I wait."
To abort -- to stop something before it finishes, on purpose
"If the key is wrong in the first four bars, we abort and start again."
Downtime -- the period when a system or a room is not working or not in use
"Eleven seconds of downtime on air feels like a very long time."
Redundancy -- having a second system that does the same job, in case the first one stops
"Redundancy is expensive until the night it is not."
To troubleshoot -- to find the cause of a problem step by step
"You do not troubleshoot on air. You switch, and you troubleshoot in the break."
Worst case -- the most serious thing that could happen, used as a planning limit
"Worst case, we lose the music for eight bars and the host keeps talking."

Stage 1.3: Grammar in Context

GRAMMAR

Read the text, then answer the questions.

In a recorded session a mistake is a delay. When you go live, a mistake is a decision, and you have about four seconds to make it. So the preparation happens in a quiet room three days earlier, and it is written in two different kinds of sentence. The first kind describes what is always true in that room: if you unplug it, the signal stops. When a cue runs long, the picture cuts and the music fades under it. No will anywhere, because these are not predictions; they are laws.

The second kind is about one specific night. If the backing track drops out, I will patch the backup from the second machine. If the singer starts in the wrong key in the first four bars, we will abort and go again. The shape is fixed: the if half stays in the present, and only the other half is allowed to look at the future. Not if the track will drop out — ever. You can also reverse the order, and when if comes second there is no comma: I will call you if anything changes.

Two more pieces. Unless means if not, so it never takes a second negative: we will not abort unless the key is wrong. And the second half does not have to be will — it can be an imperative or another modal: if it drops out, call me; if it drops out, we might lose eight bars of downtime. Everything else in the plan is vocabulary: the fallback, the redundancy, who you cue, and the rule that you never troubleshoot on air — you switch, you finish the song, and you find the cause in the break. Worst case, eight bars with no music and the host keeps talking. And it is almost never the dramatic failure: it is a glitch, or a laptop that decided to install something at eight fifty-nine.

1. Why is there no "will" in "if you unplug it, the signal stops"?
A Because "stop" is an irregular verb.
B Because it is always true, not a prediction about one night.
C Because the sentence is too short for "will".
2. What is the fixed shape of the sentence about one specific night?
A The "if" half stays in the present, and only the other half looks at the future.
B Both halves take "will", to show that both are in the future.
C The "if" half takes "will" and the other half stays in the present.
3. The text says "unless" never takes a second negative. Why?
A Because it is an informal word and informal English avoids negatives.
B Because "unless" already means "if not", so the negative is inside it.
C Because it can only be used in questions.

Stage 1.4: Grammar Tip -- First and Zero Conditional

GRAMMAR

One decision: is this always true, or is it about one specific night?

JobFormExample
Always true (a law of the room)If / When + present, presentIf you unplug it, the signal stops.
One specific future situationIf + present, will + base verbIf the track drops out, I will patch the backup.
The order can be reversedno comma when if comes secondI will call you if anything changes.
If or whenif = maybe · when = certainIf it rains, we move inside. When we go live, the door closes.
Other endings, same rulecan / might / must / imperativeIf it drops out, call me. If it drops out, we might lose eight bars.
Unless= if not, so never a second negativeWe will not abort unless the key is wrong.
The trapnever will in the if halfNot if the track will drop out. Say if the track drops out.

Stage 2: Put the Briefing in Order

Order

Three days before the show, in a quiet room. Put your contingency briefing in order.

?"First the rule that never changes: if a track drops out, the room goes quiet."
?"Now the most likely problem of the night, and it is never the dramatic one."
?"If the cue runs long, the picture will cut and the music will fade under it."
?"If the singer starts in the wrong key, we will let it run and fix it after the break."
?"There is a backup on a second machine, and I will patch it in four seconds."
?"And you, who needs to know before anything changes?"
