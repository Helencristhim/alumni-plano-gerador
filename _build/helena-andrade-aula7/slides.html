Chapter 4: The Code

The Four Pairs That Change the Operation

stop, remember, try, regret: read the second verb

Grammar Discovery

Same Verb, Opposite Fact

"He stopped monitoring the alarm."

"He did not stop to read the fault code."

"He remembered signing the checklist."

"The master tried running the section on the generator."

For each sentence, write what really happened. Example: sentence 1 = he was watching, then he was not watching.

FormWhat it doesExample
stop doing / stop to dothe activity ended / pause in order to do somethingHe stopped monitoring it = he was not watching any more. He stopped to read the code = he paused and read it.
remember doing / remember to doremember a past action / do not forget a future jobHe remembered signing it = he signed it before. Remember to sign it = sign it later.
try doing / try to dotest a method / make an effort to do something difficultHe tried running it on the generator = he tested this method.
regret doing / regret to informbe sorry about the past / formal start of bad newsHe regretted not reading the code. We regret to inform you...
The reading trapthe two forms are two different events. A wrong option in the exam changes stopped monitoring into stopped to monitor and keeps all the other words.

You do not need to write these pairs perfectly. You need to read the second verb and know what really happened.

Listening 1

Eleven Hours on Watch

The officer of the watch, six weeks later. Sound first, no text.

0:000:00
1. How long did he watch the alarm?
For two minutes. Then he stopped watching it.
2. What does he regret?
Not stopping to read the fault code. It takes fifteen seconds.
3. What does he remember about the checklist?
He remembers signing it, but not checking any item.
Writing

Write What He Said

Task: Write three short sentences about the officer. Use one starter for each sentence.

Start with:

He watched the alarm for...He regrets not...He remembers signing...
He watched the alarm for two minutes and then stopped watching it. He regrets not stopping to read the fault code. He remembers signing the checklist, but not checking it.
Writing

What Really Happened?

Task: Write the four facts of the report in order, one sentence for each: the alarm, the officer, the master, the ship.

Start with:

First, the alarm sounded at 0341. Then the officer stopped monitoring it. After that, the master tried running the section on the emergency generator. Finally, the ship lost steering for two minutes.
