Chapter 3: The Pattern

If This, Then That

if + present · will + verb

Grammar Discovery

Listen and Notice

If there is a storm, the ship will be late.
If the ship is late, we will use the backup plan.
We will use air freight if the order is urgent.
What will you do if there is a strike?

Look at the verb after IF, and the verb in the other part. Where is WILL?

UseFormExample
Real possibilityIf + present, will + verbIf the ship is late, we will use the backup plan.
Other orderwill + verb + if + presentWe will use air freight if the order is urgent.
QuestionWhat will you do if...?What will you do if there is a strike?
NegativeIf ... doesn't, ... won'tIf it doesn't rain, the truck won't be late.
CarefulNever WILL after IF: "If the ship will be late" is wrong. Present after IF, will in the other part.
