If the Container Is Late -- primeira condicional

Num plano de contingência, cada frase é uma condição: se acontecer isto, vamos fazer aquilo. Aqui você aprende a first conditional — if + presente, will + verbo — e evita o erro de todo brasileiro: will depois do if.

Etapa 1.4: Grammar Tip -- first conditional: if + presente, will + verbo

Grammar

Para uma possibilidade real: depois do if vem o presente; na outra parte vem will. A ordem das partes pode trocar — o tempo do verbo, não. / If + present, will + verb.

Uso / UseEstrutura / PatternExemplo / Example
Condição / ConditionIf + presente, will + verboIf the ship is late, we will use the backup plan. (Se o navio atrasar, vamos usar o plano B.)
Outra ordem / Other orderwill + verbo + if + presenteWe will use air freight if it is urgent. (Vamos usar frete aéreo se for urgente.)
Pergunta / QuestionWhat will you do if...?What will you do if there is a strike? (O que você vai fazer se houver greve?)
Negativa / NegativeIf ... doesn't, ... won'tIf it doesn't rain, the truck won't be late. (Se não chover, o caminhão não vai atrasar.)
Cuidado / Careful—Em português dizemos "se o navio atrasar". Em inglês, depois do if vem o presente: "if the ship is late", nunca "if the ship will be late". / Never will after if.

Etapa 3: Pronúncia

Speaking

Ouça, grave você falando e ouça de novo. Dois pontos: a vírgula depois da parte do if é uma pausa curta, e o will sai fraco, quase colado no sujeito.

If the ship is late, we will use the backup plan.
Se o navio atrasar, vamos usar o plano B.
If there is a strike, we will use another port.
Se houver greve, vamos usar outro porto.
We will use air freight if it is urgent.
Vamos usar frete aéreo se for urgente.
What will you do if there is a storm?
O que você vai fazer se houver uma tempestade?
