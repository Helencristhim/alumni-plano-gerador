Etapa 1.3: Grammar in Context

GRAMMAR

Leia o texto em voz alta, devagar, e depois responda as perguntas.

Carlos and his wife are at a restaurant in Miami. The waiter asks: "Would you like a table for two?" "Yes, please."

They read the menu. Carlos says: "I would like the fish, and my wife would like the salad." They order a glass of wine too.

At the end, Carlos says: "The check, please." The tip is not included, so he writes twenty percent.

1. O que a esposa do Carlos pede? (What does his wife order?)
A O peixe. (The fish.)
B A salada. (The salad.)
C A sobremesa. (Dessert.)
2. Por que "my wife WOULD LIKE", sem -s? (Why no -s?)
A Porque would like nunca leva -s. (Because would like never takes -s.)
B Porque é passado. (Because it is past.)
C Porque é uma pergunta. (Because it is a question.)
3. Como o garçom oferece uma mesa? (How does the waiter offer a table?)
A "You want a table?"
B "Would you like a table for two?"
C "Do you would like a table?"

Etapa 1.4: Grammar Tip -- I would like (eu gostaria)

GRAMMAR

I want (eu quero) soa forte num restaurante. I would like (eu gostaria) é o jeito educado. / "I want" sounds strong. "I would like" is the polite way.

Uso / UseEstrutura / PatternExemplo / Example
Pedido educado / Polite requestI would like + coisaI would like the fish. (Eu gostaria do peixe.)
Forma curta / Short formI would = I’dI’d like water. (Eu gostaria de água.)
Outra pessoa / Another personshe / he + would like (sem -s)My wife would like the salad. (Minha esposa gostaria da salada.)
Oferta / OfferWould you like...?Would you like dessert? (Você gostaria de sobremesa?)
Com verbo / With a verbwould like + to + verboWe would like to order. (Gostaríamos de pedir.)
Ideia-chave / Key ideaWould like nunca muda: I, you, he, she, we. Nada de -s (aula 4) aqui. E quando o garçom oferece algo, responda Yes, please ou No, thank you. / Would like never changes. Answer an offer with "Yes, please" or "No, thank you".
