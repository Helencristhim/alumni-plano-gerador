Chapter 3: The Code

I Would Like

The polite way to ask

Grammar Discovery

What Do These Four Sentences Have in Common?

"I would like a table for two."

"My wife would like the salad."

"Would you like something to drink?"

"I’d like the fish, please."

Last class: he works, with -s. Look at My wife would like. Is there an -s? Now compare I want and I would like. Which one is more polite?

JobFormExample
Polite requestI would like + thingI would like a table for two.
Short formI would = I’dI’d like the fish.
Every person, same formhe / she / we + would like (no -s)My wife would like the salad.
Offer (the waiter)Would you like + thing?Would you like some water?
Polite with a verbwould like + to + verbWe would like to order.
Short answersYes, please. / No, thank you.Would you like dessert? No, thank you.

In one line: would like = want, but polite. It never takes -s.

Chapter 4: At the Table

At the Table

One conversation, two recordings, one menu

Dialogue

A Table for Two

M
Good evening! Welcome. Would you like a table for two?
C
Yes, please. By the window, if possible.
M
Of course. Here is the menu. Would you like something to drink?
C
I would like a glass of red wine, and my wife would like water.
M
Perfect. Are you ready to order?
C
Yes. I would like the fish, and my wife would like the chicken salad.
M
Great choice. Would you like dessert later?
C
No, thank you. Just the check at the end, please.
M
Sure. And the tip is not included. Enjoy your dinner!
Comprehension

About Megan

1. What does Megan offer first?
A table for two.
2. What does Megan give them?
The menu.
3. What does Megan ask about later?
Dessert.
4. What does Megan say about the tip?
The tip is not included.

Listening 2 · A Tip About Tips

How Much Is the Tip?

A woman explains tips in American restaurants. Sound first — no text.

1. Is the tip usually included in the US?
No, it is not.
2. How much is a normal tip?
Eighteen to twenty percent.
3. Where do you write the tip?
On the check, on the line for the tip.
