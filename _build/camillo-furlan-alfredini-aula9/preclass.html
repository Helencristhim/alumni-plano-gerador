Etapa 1.3: Grammar in Context

GRAMMAR

Leia o texto em voz alta, devagar, e depois responda as perguntas.

Camillo is calling Kessler Brakes. "Hi, Laura. This is Camillo. I'm calling about my order."

"Your order is in the warehouse. The team is packing it right now. The truck is leaving at four, and the delivery is next week."

"And the invoice?" "I'm sending it now. Sorry, another customer is calling me. Can I call you back later?"

1. O que a equipe está fazendo agora? (What is the team doing now?)
A Está almoçando no armazém, perto do caminhão. (They are having lunch.)
B Está embalando o pedido. (They are packing the order.)
C Está dirigindo o caminhão. (They are driving the truck.)
2. Como se diz "Estou ligando sobre o meu pedido" em inglês?
A "I'm calling about my order."
B "I call about my order of brakes from the fair."
C "I calling about my order."
3. Por que o texto diz "is leaving" com -ing? (Why "is leaving"?)
A Porque o caminhão sai todo dia às quatro, é rotina. (Because it is a routine.)
B Porque é passado. (Because it is the past.)
C Porque é algo acontecendo agora / hoje. (Because it is happening now, today.)

Etapa 1.4: Grammar Tip -- Present continuous (estou fazendo)

GRAMMAR

Para o que está acontecendo agora, use am / is / are + verbo com -ing. É o "estou ligando" do português e o "estoy llamando" do espanhol. / For things happening now: am / is / are + verb-ing.

Uso / UseEstrutura / PatternExemplo / Example
Agora / Nowam / is / are + verbo-ingI'm calling. (Estou ligando.)
Negativa / Negativeam not / isn't / aren't + -ingWe aren't working today. (Não estamos trabalhando hoje.)
Pergunta / QuestionIs / Are + sujeito + -ing?Is the truck leaving? (O caminhão está saindo?)
No telefone / On the phoneThis is + nomeThis is Camillo. (Aqui é o Camillo.)
Ideia-chave / Key ideaAs duas peças são obrigatórias: "I calling" e "I am call" estão errados; o certo é "I am calling". Para rotina, continue com o presente simples da aula 3: "I call suppliers every week". / Two pieces: am + -ing.
