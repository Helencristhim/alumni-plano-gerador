Chapter 3 -- The Code

Yesterday's Cause, Today's Result

If we had..., we would... / If we were..., we would have...

Discovery

Four Sentences, Two Times

Read the highlighted verbs. In each sentence, which half is about the past and which half is about now?

"If the container had left on Friday, the client would have the parts today."

"If we hadn't missed the cut-off, we wouldn't be paying a penalty now."

"If we weren't such a big customer, they wouldn't have offered a discount."

"If I didn't trust Tom, I would have cancelled the order last week."

MixFormExample
past cause, present resultif + past perfect, would (not) + base verb"If the container had left on Friday, the client would have the parts today."
present fact, past resultif + past simple, would (not) have + past participle"If we weren't such a big customer, they wouldn't have offered a discount."
compare: third conditionalif + past perfect, would have + past participlepast cause, past result: "If it had left on Friday, it would have arrived on Monday."

Key idea: choose each half by its own time. "Now", "today" and "this month" ask for would + verb; "last week" and "on Friday" ask for would have + participle. Never put "would" in the if-half ("If we would have shipped").

The Structure

Three Jobs After a Delay

The same pattern, doing three different jobs in a call with a supplier.

1 · Show what the delay costs today

"If the container had left on Friday, we wouldn't have this shortfall now."

A fact, not an accusation.

2 · Use the relationship as a bargaining chip

"If we weren't long-term partners, we would have cancelled the order."

You are angry, and you want to stay.

3 · Ask for better communication

"If you had called us on Thursday, we would have a plan B today."

A request for the next time, without blame.

Notice the contractions: "wouldn't", "weren't", "hadn't" -- this is how it sounds in a real call.
